# 年賀状・お歳暮・季節の挨拶を書く

定型の挨拶を押さえつつ、一言の近況や感謝を添えて、形式だけにならないようにする。時期のずれに注意する。

## 先に確認すること
- 種類（年賀状、寒中見舞い、暑中見舞い、お歳暮など）と送る時期
- 相手との関係（取引先、恩師、友人）
- 近況や感謝を伝えたいこと
- 喪中の連絡を受けているか

## 手順
1. 時期を確認する（年賀状は元日〜1月7日、松の内を過ぎたら寒中見舞い、暑中見舞いは梅雨明け〜立秋、立秋以降は残暑見舞い）。
2. 賀詞を選ぶ。目上には「謹賀新年」「謹んで新春のお慶びを申し上げます」を使い、「賀正」「迎春」など一語の賀詞は避ける。
3. 旧年中のお礼、今年の抱負、結びの順に書く。
4. 相手が喪中の場合は、年賀ではなく寒中見舞いにする。
5. 近況を一文添える。

## 出力形式
```
（賀詞）
（旧年中のお礼）
（今年の抱負）
（一言の近況）
{日付}　{差出人}
```

## 例
入力：「取引先向けの年賀状。昨年は新規案件で世話になった。今年はさらに連携したい」
出力のポイント：
- 「謹んで新春のお慶びを申し上げます。旧年中は格別のご高配を賜り、厚く御礼申し上げます」
- 今年の抱負を一文添える。

## 注意
- 入力に無い相手の個人情報を書かない。
- 元号・干支・日付は暦で確認するよう添える。
