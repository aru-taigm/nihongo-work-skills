# 日程調整のメールを書く

相手が1往復で決められるよう、候補を3つ、曜日と時間帯つきで出す。変更依頼のときは、理由とお詫びを先に書く。

## 先に確認すること
- 打ち合わせの目的、所要時間、参加者
- 形式（対面、オンライン）と場所・URL
- こちらの空き時間
- 返答の希望期限

## 手順
1. 件名に「日程調整のお願い」と用件を入れる。
2. 目的と所要時間を最初に書く。
3. 候補日を3つ、「10/14（月）14:00〜15:00」のように曜日と時間で書く。
4. どれも難しい場合は、相手の都合の良い日時を教えてもらう旨を添える。
5. 返答期限を書く。
6. 変更依頼なら、お詫びと理由、新しい候補を書く。

## 出力形式
```
件名：【日程調整のお願い】{用件}
{宛名}様
（目的・所要時間）
候補：
・
・
・
（返答のお願い）
```

## 例
入力：「来週、A社の佐藤さんと新サービスの打ち合わせを1時間。オンライン。火曜午後、水曜午前、木曜終日が空いている」
出力のポイント：
- 候補：10/15（火）13:00〜、10/16（水）10:00〜、10/17（木）11:00〜（日付は暦で確認）。
- オンラインのURLは別途送る旨を添える。

## 注意
- 日付と曜日が合っているか、必ず確認する。
- 入力に無い日時を作らない。空き時間が不明なら「要記入」とする。
