# 営業メール・初回アプローチを書く

自社の説明ではなく、相手の課題から入る。返信のハードルを下げ、次の行動を一つに絞る。

## 先に確認すること
- 相手（会社、役職、関心事）
- 自社の提供価値と実績
- きっかけ（紹介、問い合わせ、イベント）
- 求める次の行動（資料請求、15分の面談）

## 手順
1. 件名を、相手にとっての価値が分かるように書く（「○○のコストを下げるご提案」）。
2. 冒頭で、連絡したきっかけを書く。
3. 相手の課題を想像した一文を書く（断定せず「〜ではないでしょうか」）。
4. 自社の提供価値を、数字や実績つきで1〜2文で書く。
5. 次の行動を一つ、簡単な形で提示する（「15分のオンラインで」）。
6. 配信停止や不要の旨の配慮を添える（一斉配信の場合）。

## 出力形式
```
件名：
{宛名}様
（きっかけ）
（課題の仮説）
（提供価値）
（次の行動）
```

## 例
入力：「製造業の担当者に、検品の自動化サービスを紹介。実績は検品時間を40%削減。15分の説明を取りたい」
出力のポイント：
- 「検品作業に時間がかかっていないでしょうか」と課題から入る。
- 実績：検品時間を40%削減。次の行動：15分のオンライン説明。

## 注意
- 入力に無い実績・顧客名を使わない。
- 特定電子メール法など、法令の確認を添える（一斉送信や個人宛て）。
