# 目標（OKR・MBO）を作る

目標は「測れる」「期限がある」「少し難しい」の三点を満たす。活動（やること）ではなく、成果（どうなるか）で書く。

## 先に確認すること
- 期間、所属と役割
- 会社・部門の方針
- 今期に達成したいこと
- 現状の数字（基準値）

## 手順
1. 目的（Objective）を、方向性が分かる一文にする（数字を入れない）。
2. 主要な成果（Key Result）を2〜4個、数値と期限つきで書く。
3. 各KRに、現状の値と目標値を書く。
4. KRの達成に向けた主な施策（イニシアチブ）を書く。
5. 測れない目標は、代わりの指標を提案する。
6. MBOなら、目標・達成基準・ウェイトを表にする。

## 出力形式
```
Objective：
KR1：現状→目標（期限）
KR2：
KR3：
主な施策：
```

## 例
入力：「営業職。今期は新規顧客を増やしたい。今は月2件の商談が取れている」
出力のポイント：
- Objective：新規顧客の開拓を安定させる。
- KR1：月の新規商談を2件から6件に（第3四半期末まで）。

## 注意
- 入力に無い現状の数値を作らない。基準値が不明なら「要記入」とする。
- 評価制度に使う場合は、会社の制度に合わせるよう添える。
