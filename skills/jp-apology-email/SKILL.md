# お詫びのメールを書く

言い訳を並べず、「事実 → お詫び → 原因 → 対応 → 再発防止」の順で、相手が次に取る行動まで示す。

## 先に確認すること
- 何が起きたか（事実、影響範囲）
- 原因が分かっているか
- 今すぐできる対応と、その期限
- 相手に負担をかけること（再送、確認、返金など）

原因が分からないときは、分からないと正直に書き、判明する時期を約束する。

## 手順
1. 件名に「お詫び」を入れる（例：【お詫び】納品遅延のご連絡）。
2. 冒頭で事実とお詫びを一文で述べる。
3. 原因は、責任転嫁に聞こえない書き方にする（取引先や個人のせいにしない）。
4. 対応は「いつまでに、何をするか」を日付つきで書く。
5. 再発防止は、実行できる具体策だけを書く。「気をつけます」で済ませない。
6. 最後にもう一度短くお詫びし、連絡先を示す。

## 出力形式
```
件名：【お詫び】{事柄}について

{宛名}様

お世話になっております。{自社名}の{氏名}です。

このたびは、{事実}により、{影響}をおかけしましたこと、深くお詫び申し上げます。

【経緯・原因】
【対応】
【再発防止策】

重ねてお詫び申し上げます。ご不明な点は{連絡先}までお知らせください。
```

## 例
入力：「納品が3日遅れる。担当者が体調不良で確認作業が遅れた。明後日に納品する。チェック体制を二人制にする」
出力のポイント：
- 経緯：「担当者の体調不良により、納品前の確認作業が遅れました」
- 対応：「〇月〇日（水）に納品いたします」
- 再発防止：「今後は確認作業を二名体制で行います」

## 注意
- 入力に無い補償、割引、期日を勝手に約束しない。
- 法的責任に関わる内容は、送る前に上長や法務に確認するよう添える。
