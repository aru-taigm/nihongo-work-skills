# 社内チャットの文面を書く

メールより短く、しかし何をしてほしいかは明確に。相手の通知を開いた最初の2行で内容が伝わるようにする。

## 先に確認すること
- 相手（上司、同僚、他部署、複数人のチャンネル）
- 目的（依頼、質問、報告、相談）と、期限
- 前提を共有しているか（初めて話す相手か）

## 手順
1. 1行目に、相手へのお願いまたは結論を書く（「〇〇の確認をお願いできますか」）。
2. 背景は1〜2行。長い場合はスレッドか別資料に分ける。
3. 期限は日時で書く（「今日中」ではなく「今日17時まで」）。
4. 選択肢で答えられる質問にする（「AとBのどちらがよいですか」）。
5. 複数人向けは、宛先を明示する（@名前）。全員宛に曖昧に頼まない。
6. 目上の相手には「です・ます」で、メールほど硬くしない。絵文字は相手との関係で控える。
7. 感謝を一言添える。

## 出力形式
```
{宛先}
{お願い／結論}
{背景（1〜2行）}
{期限}
{一言}
```

## 例
入力：「佐藤さんに、明日の会議資料の最終確認を今日の17時までに頼みたい。修正が多いと間に合わない」
出力：
```
@佐藤さん
明日の会議資料の最終確認をお願いできますか？ 今日の17時までにいただけると助かります。
修正が多い箇所は先に共有いただけると、こちらで調整します。
お忙しいところすみません、よろしくお願いします。
```

## 注意
- 入力に無い日時や資料名を作らない。
- 感情的な内容や叱責は、チャットでなく対面か通話を勧める。
