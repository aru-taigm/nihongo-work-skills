# 値上げ・変更のお知らせを書く

結論と実施日を先に書き、理由を誠実に説明し、顧客への影響と選択肢を示す。言い訳や過度な謝罪を避ける。

## 先に確認すること
- 変更の内容と実施日
- 理由（原価、品質維持）
- 顧客への影響（金額、手続き）
- 対応の選択肢、問い合わせ先

## 手順
1. 件名に「価格改定のお知らせ」など、変更の内容を書く。
2. 冒頭で、変更の内容と実施日を書く。
3. 理由を、事実に沿って簡潔に説明する。
4. 新旧の価格、対象を表で示す。
5. 顧客が取れる選択肢（現行価格での契約更新期限、解約方法）を書く。
6. お詫びと、これまでのお礼を書く。
7. 問い合わせ先を書く。

## 出力形式
```
件名：【お知らせ】{変更内容}について
{宛名}様
（変更内容と実施日）
（理由）
（新旧の価格）
（ご対応のお願い・選択肢）
（お詫びとお礼）
```

## 例
入力：「来年1月から、月額1,000円を1,200円に値上げ。原材料の高騰が理由。1月末までは現行価格で更新できる」
出力のポイント：
- 「1月1日より、月額料金を1,000円から1,200円に改定いたします」（年月日は入力に合わせる）
- 選択肢：1月末までは現行価格で更新可能。

## 注意
- 入力に無い理由・補償を作らない。
- 法令（特定商取引法、契約条件の変更の手続き）は、確認するよう添える。
