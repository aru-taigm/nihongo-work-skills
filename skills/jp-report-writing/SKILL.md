# レポート・小論文を書く（構成と文章）

「問い → 主張 → 根拠 → 反論への応答 → 結論」が通っているかを軸に、構成と文章を整える。内容の捏造や代筆ではなく、書き手の考えを組み立てる手伝いをする。

## 先に確認すること
- 課題文、字数、締切、評価の観点
- 書き手の立場・主張（まだ無ければ、一緒に決める）
- 使ってよい資料と、引用の形式

## 手順
1. 課題から「問い」を一文にする。
2. 主張（結論）を一文で書く。「〜と考える」で終わらせず、理由が続くようにする。
3. 根拠を2〜3個出す。各根拠に、事実・データ・出典を付ける。出典が無いものは「要出典」とする。
4. 想定される反論を一つ挙げ、それにどう応えるかを書く。
5. 構成は「序論（問いと主張）→ 本論（根拠ごとに章）→ 結論」にする。
6. 文章は、常体（だ・である）に統一する。一文を60字程度に収め、主語と述語を近づける。
7. 「思う」「感じる」の多用を避け、根拠のある断定にする。ただし根拠が弱いときは断定しない。
8. 引用は、鉤括弧と出典（著者、年、ページ）を明記する。他人の文章を無断で写さない。

## 出力形式
```
【問い】
【主張】
【構成案】序論／本論1／本論2／反論と応答／結論
【本文】（指示があれば）
【確認事項】出典・字数・不足している根拠
```

## 例
入力：「課題：スマホの学校持ち込みの是非。字数1200字。賛成の立場で」
出力のポイント：
- 主張：「学習の補助手段として、スマホの持ち込みを条件つきで認めるべきだ」
- 根拠1：調べ学習での利用（出典が必要）。反論：授業中の私的利用。応答：使用ルールの明確化。

## 注意
- 入力に無い統計や文献を作らない。引用が必要な箇所には「要出典」と書く。
- 課題の提出物の代筆ではなく、構成や文章の改善の支援として扱う。
