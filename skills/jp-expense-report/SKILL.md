# 経費精算書を作る

経理が確認する観点（日付、金額、目的、証憑、勘定科目）が揃った精算書にして、差し戻しを減らす。

## 先に確認すること
- 精算の対象期間と、社内の精算ルール（上限、事前申請が必要な項目）
- 領収書があるか（無いものは、その理由）
- 出張や会食の場合、目的と同行者

## 手順
1. 明細を日付順に並べ、「日付・内容・金額・支払先・目的」の表にする。
2. 目的が空欄のものは、推測せず質問する（特に会食、タクシー）。
3. 区分を付ける：交通費、宿泊費、会議費、接待交際費、消耗品費、通信費、その他。
4. 会食は、参加者の人数と社名・氏名を書く欄を入れる（一人あたりの金額も出す）。
5. 領収書の宛名、日付、但し書き、金額が精算内容と一致しているか点検する。
6. 合計を出し、立替金額と照らす。

## 出力形式
```
経費精算書
申請者：　所属：　申請日：　対象期間：

| 日付 | 区分 | 内容・目的 | 支払先 | 金額 | 領収書 |
|---|---|---|---|---|---|

合計：
概要（出張なら行き先と目的）：
```

## 例
入力：「10/3 新幹線 東京〜大阪 14,720円（クライアント訪問）、10/3 タクシー 2,300円（領収書なし）」
出力のポイント：
- 新幹線：交通費、領収書あり。
- タクシー：領収書なしのため「領収書なし（理由：）」として、理由の記入を促す。

## 注意
- 入力に無い金額、目的、同行者を作らない。
- 私用の支出が混ざっていないか、最後に確認する。
