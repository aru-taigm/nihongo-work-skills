# 契約書の確認ポイントを洗い出す

読み落としやすい条項を整理して、人間や専門家が判断するための材料を出す。有効・無効や法的な結論は述べない。

## 先に確認すること
- 自分の立場（発注者／受注者、貸す側／借りる側）
- 契約の種類（業務委託、NDA、売買、利用規約など）
- 金額、期間、納期、成果物

## 手順
1. 次の観点で条項を探し、該当する条文番号と要約を書く。
   - 業務範囲、成果物、検収の方法と期限
   - 報酬、支払時期、経費の負担
   - 知的財産権（著作権の帰属・譲渡、二次利用、著作者人格権の不行使）
   - 秘密保持の範囲と期間
   - 再委託の可否
   - 契約期間、自動更新、中途解約の条件、違約金
   - 損害賠償（上限の有無、範囲）
   - 禁止事項、競業避止
   - 準拠法、管轄裁判所
   - 反社会的勢力の排除
2. 自分の立場から見て不利になりうる点を「注意」として挙げ、理由を一文で書く。
3. 条文に書かれていない（欠けている）重要事項も挙げる（例：検収期限が無い、支払日が無い）。
4. 修正を依頼するなら、どう直したいかの文案を添える。

## 出力形式
```
■ 契約の概要
■ 条項チェック（条文番号／内容／注意）
■ 欠けている事項
■ 修正を依頼する場合の案
■ 専門家に確認したほうがよい点
```

## 例
入力：「受注者の立場。第8条：成果物の著作権（翻案権等を含む）は納品時に委託者に譲渡する。損害賠償の上限の定めなし」
出力のポイント：
- 注意：著作権を全部譲渡する内容。自作の素材やノウハウの再利用が制限されるおそれがある。
- 注意：損害賠償の上限がなく、報酬額を超える負担になりうる。

## 注意
- 「法的に問題ない」「無効」などと断定しない。最終判断は弁護士に確認するよう添える。
- 契約書の内容を要約するときは、原文から離れた言い換えをしない。
