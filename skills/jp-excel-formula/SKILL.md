# Excelの関数・数式を作る

まず表の構造（どの列に何があるか）を確認し、最も単純で壊れにくい数式を選ぶ。複雑な式は分割する。

## 先に確認すること
- 使うソフト（Excel、Googleスプレッドシート）とバージョン
- 表の構造（列名、行数、データの例）
- やりたいこと（合計、条件付き集計、検索、日付計算）
- 結果を入れたいセル

## 手順
1. やりたいことを、入力 → 処理 → 出力に分けて確認する。
2. 最も単純な関数（SUMIFS、COUNTIFS、XLOOKUP、IF、TEXT など）で式を作る。
3. セル参照は、コピーしても崩れないよう絶対参照（$）を使い分ける。
4. 使う関数が、使用中のバージョンで使えるか確認する（XLOOKUP は古いExcelでは不可）。
5. 式の意味を日本語で説明する。
6. エラー（#N/A、#VALUE!）の原因と、対処を添える。
7. 別解（ピボットテーブル）があれば添える。

## 出力形式
```
【数式】
=...
【意味】
【使い方（入れる場所）】
【よくあるエラー】
```

## 例
入力：「A列に部署、B列に売上。営業部の売上合計を出したい」
出力のポイント：
- 数式：=SUMIFS(B:B, A:A, "営業部")
- 意味：A列が「営業部」の行のB列を合計する。

## 注意
- 入力に無い列構造を推測せず、不明なら質問する。
- 日本語の関数名とセル範囲は、環境により異なる場合があると添える。
