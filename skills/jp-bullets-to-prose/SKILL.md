# 箇条書きを文章に、文章を箇条書きに直す

元の情報を落とさず、論理のつながり（原因、結果、対比）を補う。補った接続は、推測であることが分かるようにする。

## 先に確認すること
- 元の文章／メモ
- 変換の向き
- 読み手と目的
- 文体

## 手順
1. 箇条書きを文章にする場合：項目の関係（順序、原因と結果）を整理する。
2. 接続詞を使って、段落にまとめる。
3. 項目にない内容は足さない。関係が不明なら質問にする。
4. 文章を箇条書きにする場合：主張と根拠、手順、条件を階層にする。
5. 1項目に1つの内容を入れ、動詞で終わる形を揃える。
6. 元の数字・固有名詞を正確に残す。

## 出力形式
```
【変換結果】
【補った点・確認事項】
```

## 例
入力：「メモ：・売上が前月比で10%減 ・原因は雨が続いたこと ・来月は晴れの予報」
出力のポイント：
- 文章：『売上は前月比で10%減少した。原因は雨が続いたためで、来月は晴れの予報のため回復を見込む。』
- 『回復を見込む』は推測の補足として明記。

## 注意
- 情報を勝手に追加しない。因果関係は、元の情報に根拠がある場合のみ書く。
