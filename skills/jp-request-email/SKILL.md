# 依頼・日程調整・お断りのメールを書く

頼みごとは、相手の負担を減らし、断りやすさにも配慮する。何を、いつまでに、どうやってほしいかを迷わせない。

## 先に確認すること
- 依頼の内容と、相手が最初に取る行動
- 期限と、期限の理由
- 相手との関係（初めてか、継続的な取引か）

## 手順（依頼）
1. 件名に「依頼」「ご相談」など用件を入れる。
2. 依頼の背景を一文で書き、なぜその相手に頼むのかを添える。
3. 依頼事項を番号つきで書く。期限は日付と曜日で書く。
4. 難しい場合は代替案や一部対応でも構わないことを書く。

## 手順（日程調整）
1. 候補日時を3つ程度出す（曜日と時間帯つき）。
2. 所要時間、場所またはオンラインの形式を書く。
3. 「上記が難しければ、ご都合の良い日時をお知らせください」と結ぶ。

## 手順（お断り）
1. 感謝を先に述べる。
2. 断る理由を、可能な範囲で短く書く。
3. 明確に断る（「検討します」とあいまいにしない）。
4. 可能なら代替案や、今後の関係につながる一言を添える。

## 出力形式
```
件名：

{宛名}様

お世話になっております。{自社名}の{氏名}です。

（背景を一文）

つきましては、下記についてお願いできませんでしょうか。
1.
2.
期限：{日付（曜日）}

ご多忙のところ恐れ入りますが、何卒よろしくお願い申し上げます。
```

## 例
入力：「来週、打ち合わせをしたい。火曜午後か木曜午前、30分、オンライン」
出力のポイント：
- 「30分程度、オンラインでお時間をいただけますでしょうか」
- 候補：〇月〇日（火）13:00〜17:00のうち／〇月〇日（木）10:00〜12:00のうち。

## 注意
- 入力に無い日付、金額、約束を作らない。
- 「できれば」「もし可能でしたら」を重ねて、依頼の中身が曖昧にならないようにする。
