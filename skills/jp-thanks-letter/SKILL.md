# お礼のメール・手紙を書く

「ありがとうございました」だけの定型文にしない。相手が何をしてくれたか、それで自分がどうなったかを一文入れる。

## 先に確認すること
- 相手との関係、お礼の理由
- 相手がしてくれた具体的なこと（時間、助言、紹介、贈り物など）
- 今後のつながり（次の予定、報告したいこと）

## 手順
1. 早く送る（商談や面接なら当日か翌営業日中）。
2. 冒頭で具体的なお礼を述べる。
3. 相手の言葉や、印象に残った点を一つ引用し、自分の今後の行動につなげる。
4. 面接後の場合、志望の気持ちは一文で。長く書かない。
5. 結びに、次の連絡や予定があれば書く。

## 出力形式
```
件名：【御礼】{場面}のお礼

{宛名}様

本日は、{場面}のお時間をいただき、誠にありがとうございました。

（具体的なお礼と、学んだこと・印象）

（今後の行動）

今後ともどうぞよろしくお願い申し上げます。
```

## 例
入力：「面接の翌日。面接官の山田さんが、チームの開発フローを詳しく説明してくれた。入社したい気持ちが強まった」
出力のポイント：
- 「チームの開発フローを具体的にご説明いただき、入社後の働き方を鮮明に想像できました」
- 「貴社で力を発揮したいという思いが、いっそう強くなりました」

## 注意
- 入力に無いエピソードを作らない。具体例が無ければ、足りない旨を伝えて質問する。
- 過度なへりくだりや、長い文面は避ける。
