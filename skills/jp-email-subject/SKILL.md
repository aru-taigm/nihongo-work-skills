# メールの件名を改善する

件名だけで「誰から、何の用件で、何をしてほしいか、いつまでか」が分かるようにする。

## 先に確認すること
- メールの本文または用件
- 相手との関係
- 返信や対応を求めるか、期限

## 手順
1. 用件を一言にする。
2. 必要な場合は、冒頭に【依頼】【ご報告】【至急】などを付ける。
3. 日付や案件名を入れ、検索しやすくする。
4. 30字前後に収める（スマホで切れないよう、重要語を前に置く）。
5. 返信のときは、元の件名を変えるか、変えるなら理由を添える。
6. 件名を3案出し、特徴を一言で添える。

## 出力形式
```
案1：
案2：
案3：
（それぞれの狙い）
```

## 例
入力：「来週の定例会議の資料を、金曜までに共有してほしいと頼むメール」
出力のポイント：
- 案1：【依頼】定例会議（10/18）資料のご共有（10/11まで）。
- 案2：10/18定例会議の資料ご提出のお願い。

## 注意
- 入力に無い日付・案件名を作らない。
- 「至急」の乱用を避ける。
