# 学校・園への連絡を書く

先生は多くの連絡を見る。用件と、お願いしたいことを最初に書く。病名などの個人情報は必要な範囲にとどめる。

## 先に確認すること
- 子どもの学年・クラス・名前
- 連絡の内容（欠席、遅刻、相談）
- 日付、理由
- お願いしたいこと

## 手順
1. 最初に、学年・クラス・名前と用件を書く。
2. 日付を曜日つきで書く。
3. 理由は簡潔に（「体調不良のため」「発熱のため」）。
4. お願い（宿題、配布物、お迎え）を具体的に書く。
5. 相談の場合は、事実、困っていること、お願いしたい配慮を分けて書く。
6. 結びに、お礼と、連絡のつく時間帯を書く。

## 出力形式
```
{先生名}先生
{学年・クラス}{子どもの名前}の{用件}です。
（日付と理由）
（お願い）
{保護者名}
```

## 例
入力：「3年2組の山田太郎。明日（金）、発熱で休む。宿題と配布物をお願いしたい」
出力のポイント：
- 「明日（金）、発熱のため欠席いたします」
- 宿題・配布物は、友人に届けてもらうか、後日受け取るか、お願いの方法を確認。

## 注意
- 入力に無い病名・事情を書かない。
- 日付と曜日が合っているか確認する。
