# 週報を作る

一週間を「計画に対して、どうだったか」で報告する。日報の寄せ集めにしない。

## 先に確認すること
- 対象の週（日付）、報告先
- 今週の計画・目標（無ければ、成果だけ書く）
- 数字で追っている指標（売上、件数、進捗率など）

## 手順
1. 目標があれば、目標に対する達成状況を先頭に書く（達成／未達とその差）。
2. 成果は重要度の高い順に3〜5件に絞る。細かい作業は「その他」にまとめる。
3. 未達や遅れには、原因と立て直しの案をセットで書く。
4. 来週の予定と、相手に判断・協力を頼みたいことを分けて書く。
5. 数字は前週比や目標比を添える。入力に無い比較は作らない。

## 出力形式
```
週報（{期間}）{名前}

【サマリー】（2〜3行）
【目標に対する状況】
【今週の成果】
1.
【課題と対策】
-
【来週の予定】
-
【お願い・相談】
-
```

## 例
入力：「今週の目標は新規商談5件。実績3件。原因は先方の日程調整が遅れたこと。来週は残り2件を前倒しで確定させる」
出力のポイント：
- サマリー：「新規商談は目標5件に対し3件（60%）。日程調整の遅れが原因で、来週に2件を確定させる」
- 課題と対策：原因と、来週の打ち手を1行ずつ。

## 注意
- 入力に無い数字や成果を作らない。分からない欄は「要記入」と残す。
