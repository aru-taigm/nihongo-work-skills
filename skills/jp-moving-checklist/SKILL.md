# 引越しの手続きを整理する

期限のあるもの（転出届は引越しの14日前から）と、早めに予約が必要なもの（引越し業者、インターネット）を先に並べる。

## 先に確認すること
- 引越し日
- 現住所と新住所の自治体
- 世帯構成（子ども、車、ペット）
- 賃貸か持ち家か

## 手順
1. 引越し1〜2か月前：賃貸の解約、引越し業者の予約を並べる。
2. 2週間前〜直前：役所の手続き、ライフライン（電気・ガス・水道）の連絡を並べる。
3. 当日：立ち会い、新居の確認を並べる。
4. 引越し後：転入届、運転免許・マイナンバーカードの住所変更、郵便の転送を並べる。
5. 家族構成に応じた手続き（児童手当、転校、車庫証明）を追加する。
6. 期限と、窓口（役所、オンライン）を添える。
7. 自治体ごとに異なる点は、各自治体の案内で確認するよう添える。

## 出力形式
```
【1〜2か月前】
【2週間前〜直前】
【当日】
【引越し後】
```

## 例
入力：「来月、東京都内から横浜へ。一人暮らしで賃貸。車は無し」
出力のポイント：
- 解約の連絡は更新時期や予告期間の契約を確認。
- 転出届（旧住所）、転入届（新住所）の期限は、自治体の案内で確認。

## 注意
- 入力に無い日付・自治体の規則を作らない。
- 期限と窓口は、自治体の公式案内で確認するよう添える。
