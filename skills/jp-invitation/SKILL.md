# 案内状・招待メールを書く

受け取った人が「行くか」「いつ返事するか」を決められるよう、5W1Hを漏れなく書く。

## 先に確認すること
- イベントの名称、目的、対象者
- 日時、場所（地図・最寄り駅）またはオンラインのURL
- 参加費、定員、締切、申込方法
- 主催者と問い合わせ先

## 手順
1. 件名に【ご案内】と、イベント名・日付を入れる。
2. 冒頭に、日時・場所・参加費を1〜2行で書く。
3. 開催の趣旨と、参加するとどんな得があるかを短く書く。
4. プログラム（時刻つき）を箇条書きにする。
5. 申込方法と締切を、日付と曜日で明記する。
6. 懇親会がある場合は、会費と、アレルギー等の申告方法を書く。
7. 欠席する場合の連絡方法も添える。

## 出力形式
```
件名：【ご案内】{イベント名}（{日付}）

各位

■ 日時
■ 会場
■ 参加費／定員
■ 内容（プログラム）
■ お申し込み方法（締切）
■ お問い合わせ先
```

## 例
入力：「11/15（金）14時から、新製品の勉強会。本社5階。無料。定員30名。申込は11/8まで、返信メールで」
出力のポイント：
- 冒頭：「11月15日（金）14:00より、本社5階で新製品の勉強会を開催します（参加無料、定員30名）」
- 申込：「11月8日（金）までに、本メールへのご返信でお申し込みください」（曜日は暦で確認するよう添える）。

## 注意
- 入力に無い会場名、費用、講師名を作らない。
- 日付と曜日が合っているか、必ず確認する。
