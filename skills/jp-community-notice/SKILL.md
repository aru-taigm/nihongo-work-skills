# 自治会・PTA・サークルのお知らせを書く

読む人の年齢や関心が幅広いので、日時・場所・持ち物・申込をまず上に書く。依頼は具体的に、お願いの理由を添える。

## 先に確認すること
- 行事・連絡の内容
- 日時、場所、対象
- 持ち物、参加費、申込
- 問い合わせ先

## 手順
1. 見出しに、行事名と日付を入れる。
2. 最初に日時、場所、持ち物、参加費をまとめる。
3. 目的や背景を、短く書く。
4. 申込方法と締切を、日付と曜日で書く。
5. 中止や変更の場合の連絡方法を書く。
6. 問い合わせ先を書く（個人の電話番号の扱いに配慮）。
7. 読みやすい大きさ・やさしい言葉で書く。

## 出力形式
```
{行事名}のお知らせ
日時／場所／対象／持ち物／参加費
（趣旨）
申込方法／締切
問い合わせ先
```

## 例
入力：「町内の清掃活動。11月3日（日）9時から。公園に集合。軍手を持参。雨天中止」
出力のポイント：
- 日時：11月3日（日）9時、公園集合。持ち物：軍手。
- 雨天中止の連絡方法は要記入。

## 注意
- 入力に無い日程・連絡先を作らない。
- 個人情報（電話番号、住所）の掲載範囲に配慮する。
