# 会議の進行（ファシリテーション）を設計する

会議は「決める・共有する・考える」のどれかを先に決める。決める会議は、論点と判断基準を事前に共有する。

## 先に確認すること
- 会議の目的と、決めたいこと
- 参加者と、役割
- 時間
- 事前資料

## 手順
1. 会議の種類（決定、共有、ブレスト）を決める。
2. ゴール（会議後に何が決まっているか）を一文で書く。
3. 議題ごとに、時間・担当・必要な結論（決定か共有か）を書く。
4. 事前に共有する資料と、読む時間を決める。
5. 発言が偏らないよう、順番や付箋などの方法を決める。
6. 時間が余ったら・足りなくなったらの対応を決める。
7. 最後に、決定事項・担当・期限を読み上げて確認する。

## 出力形式
```
【目的・ゴール】
【進行表】
| 時間 | 議題 | 担当 | 結論の種類 |
【事前準備】
【終了時の確認】
```

## 例
入力：「週次の定例を30分で。新機能の優先順位を決めたい。参加者は5人」
出力のポイント：
- 進行：5分 前回の確認、15分 優先順位の議論、5分 決定、5分 確認。
- ゴール：新機能の優先順位が決まっている。

## 注意
- 入力に無い議題・人名を作らない。
- 参加者の状況（時差、オンライン）に配慮するよう添える。
