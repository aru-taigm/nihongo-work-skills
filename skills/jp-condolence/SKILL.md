# お悔やみの文面を書く

遺族の心情に配慮し、簡潔に。ビジネスでは、会社としての弔意と、個人としての弔意を分けて考える。

## 先に確認すること
- 故人との関係、遺族との関係（取引先の担当者、同僚、上司など）
- 手段（メール、弔電、手紙、香典に添える文）
- 宗教・宗派（分からなければ、無宗教に近い一般的な表現にする）
- 通夜・葬儀の日程と、参列できるか

## 手順
1. 冒頭に前置き（頭語、時候の挨拶）は書かない。お悔やみの言葉から始める。
2. 忌み言葉を避ける。
   - 重ね言葉：重ね重ね、たびたび、くれぐれも、ますます、まだまだ など
   - 不幸が続くことを連想させる言葉：続いて、再び、追って など
   - 直接的な表現：死ぬ、死亡、生きる → 「ご逝去」「ご生前」
3. 宗教によって使えない言葉に注意する（例：「成仏」「供養」は仏教、「冥福」は仏教、キリスト教では「安らかに」など）。分からなければ「ご冥福」を避け「謹んでお悔やみ申し上げます」とする。
4. メールは簡潔に。参列できない場合は、理由を詳しく書かず、お詫びと弔意だけにする。
5. 返信を求めない一言（「ご返信には及びません」）を添えるとよい。
6. 差出人は、会社名と氏名、肩書きを入れる。

## 出力形式
```
件名：（お悔やみ）
{宛名}様
このたびはご逝去の報に接し、心よりお悔やみ申し上げます。
（簡潔な弔意）
ご返信には及びません。
```

## 例
入力：「取引先の佐藤部長が亡くなったという連絡を、佐藤さんの部下の田中さんから受けた。通夜には行けない」
出力のポイント：
- 「ご逝去の報に接し、驚きとともに、謹んでお悔やみ申し上げます」
- 「やむを得ぬ事情で参列がかないません。失礼をお許しください」

## 注意
- 入力に無い故人の経歴や死因に触れない。
- 地域や宗派で作法が異なるため、迷う場合は会社の総務や詳しい人に確認するよう添える。
