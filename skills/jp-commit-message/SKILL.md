# コミットメッセージを書く

件名は「何をしたか」を50字程度で書き、本文は「なぜそうしたか」を書く。差分を読めば分かる「何を」は繰り返さない。

## 先に確認すること
- 差分または変更内容
- 規約（Conventional Commits など）
- 関連するIssue
- 言語（日本語、英語）

## 手順
1. 規約を確認する（feat:、fix: などの接頭辞があるか）。
2. 件名を命令形または体言止めで、50字程度に書く。
3. 空行を挟んで、本文に理由・背景・影響を書く。
4. 関連するIssue番号を書く。
5. 1つのコミットに複数の目的が混ざっていたら、分けることを提案する。
6. 破壊的な変更は、本文で明記する。

## 出力形式
```
{件名}

{本文：理由と背景}

Refs: #{番号}
```

## 例
入力：「ログイン時のエラー処理を追加した。入力が空のときに落ちていた」
出力のポイント：
- 件名：fix: ログイン時の空入力でクラッシュする問題を修正
- 本文：空の入力を検証せずに処理していたため、事前に検証を追加した。

## 注意
- 入力に無い変更を書かない。
- Co-Authored-By などの付記は、プロジェクトの規約に従う。
