# アンケートを設計する

「何を知りたいか」から逆算して設問を作る。設問は少なく、答えやすく、集計しやすくする。

## 先に確認すること
- 調査の目的と、結果で何を決めるか
- 回答者と人数
- 回答にかけてよい時間
- 集計方法（Googleフォーム、紙、スプレッドシート）

## 手順
1. 目的を一文にし、知りたいこと（仮説）を3〜5個に絞る。
2. 設問は1問1論点にし、誘導的な言い方を避ける。
3. 選択式を中心に、最後に自由記述を1問置く。
4. 選択肢は網羅的で排他的にし、「その他」を用意する。
5. 満足度は5段階などの尺度を揃える。
6. 所要時間を目安（5分以内）に収める。
7. 回答の取り扱い（匿名か、用途）を冒頭に明記する。

## 出力形式
```
【目的】
【設問一覧】Q1（種類：単一選択／複数選択／5段階／自由記述）…
【集計の観点】
```

## 例
入力：「勉強会の参加者30人に、内容の満足度と次回のテーマの要望を知りたい。5分で答えられるように」
出力のポイント：
- Q1：全体の満足度（5段階）、Q2：内容の難しさ（易しい〜難しい）、Q3：次回のテーマ（複数選択＋その他）、Q4：自由記述。

## 注意
- 入力に無い調査対象の属性を作らない。
- 個人を特定できる設問は、必要性を検討し、取り扱いを明記する。
