# 電話・トークスクリプトを作る

相手の時間を奪わないよう、最初の30秒で要件と相手のメリットを伝える。台本は覚えるためでなく、迷わないための骨子。

## 先に確認すること
- 目的（アポ、資料送付、販売）
- 相手の属性
- 提供価値と実績
- よくある断り文句

## 手順
1. 冒頭：名乗り、用件、所要時間（「1分だけよろしいでしょうか」）を言う。
2. 本題：相手のメリットを一文で伝える。
3. 質問を2つ用意し、相手に話してもらう。
4. 断り文句ごとに、切り返しを用意する（反論を否定せず、受け止めてから返す）。
5. クロージングで、次の約束（日時）を提案する。
6. 断られた場合の引き際と、お礼の言葉を用意する。

## 出力形式
```
【冒頭】
【本題】
【質問】
【想定される断りと切り返し】
【クロージング】
【引き際】
```

## 例
入力：「飲食店に、予約管理システムを紹介する電話。目的は15分の説明のアポ」
出力のポイント：
- 冒頭：「○○と申します。予約管理についてのご案内で、1分だけお時間よろしいでしょうか」
- 断り「忙しい」→「ごもっともです。5分だけ、いつならよろしいでしょうか」。

## 注意
- 入力に無い実績・割引を作らない。
- しつこい勧誘や、虚偽の説明を勧めない。特定商取引法などの確認を添える。
