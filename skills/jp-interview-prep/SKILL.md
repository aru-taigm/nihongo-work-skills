# 面接対策（想定問答）を作る

暗記した模範解答ではなく、本人の事実に基づく「自分の言葉」で話せる答えの骨子を作る。結論 → 理由 → 具体例の順に組む。

## 先に確認すること
- 応募先の企業・職種と、募集要項
- 本人の経歴・実績・強み
- 面接の種類（一次、最終、グループ）
- 不安な質問（退職理由、ブランクなど）

## 手順
1. 定番の質問（自己紹介、志望動機、強みと弱み、退職理由、キャリアの展望）を挙げる。
2. 各質問に、結論・理由・具体例の骨子を作る。
3. 具体例は、本人の入力にある事実だけを使う。
4. 答えにくい質問（退職理由、ブランク）は、前向きな事実を先に置く言い方を提案する。
5. 深掘りされそうな点と、その答え方を示す。
6. 逆質問を3つ、調べれば分かることを避けて考える。
7. 1つの答えを60秒（約300字）に収める。

## 出力形式
```
【想定質問と答えの骨子】
Q1：
結論／理由／具体例
【深掘りへの備え】
【逆質問】
```

## 例
入力：「営業職の転職。前職は法人営業3年、売上は目標の110%。退職理由は成長の機会を求めて」
出力のポイント：
- 志望動機：結論（御社の○○に貢献したい）→ 理由 → 前職の110%達成を具体例に。
- 逆質問：入社後3か月で期待される成果は何か。

## 注意
- 入力に無い実績や資格を作らない。
- 嘘や誇張を勧めない。事実の言い方を整える支援に徹する。
