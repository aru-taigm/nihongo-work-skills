# READMEを日本語で書く・翻訳する

最初の10秒で「これは何で、誰が使い、どう動かすか」が伝わるようにする。コードブロックとコマンドは原文のまま残す。

## 先に確認すること
- プロジェクトの目的
- 対象の読者
- インストール・使い方
- ライセンス、貢献方法

## 手順
1. 冒頭に、一文でプロジェクトの説明を書く。
2. 特徴を3〜5点の箇条書きにする。
3. インストールと使い方を、コピーして動かせる手順にする。
4. コードブロック、コマンド、URL、ファイル名は翻訳しない。
5. 見出しの構成を英語版と揃え、リンクの飛び先（アンカー）が壊れないようにする。
6. ライセンスと貢献方法を書く。
7. スクリーンショットや動画を入れる場所を指示する。

## 出力形式
```
# {名前}
（一文の説明）
## 特徴
## インストール
## 使い方
## ライセンス
```

## 例
入力：「英語READMEを日本語に。コードブロックは3つ、見出しは5つ」
出力のポイント：
- コードブロックは原文のまま、説明文のみ翻訳。
- 見出し数・順番を英語版と揃える。

## 注意
- 入力に無い機能・動作を書かない。
- 動かせない手順を書かないため、コマンドは原文を確認する。
