# お断りのメールを書く

断る理由は端的に、感謝と代案を添える。曖昧に濁すと相手が次の行動を決められないので、結論ははっきり書く。

## 先に確認すること
- 断る対象（依頼、提案、誘い）と相手との関係
- 断る理由として書いてよい範囲
- 代案（時期をずらす、他を紹介する）の有無
- 今後の関係を続けたいか

## 手順
1. 件名に元の件名と「お返事」を入れる。
2. 感謝を一文で書く。
3. 結論（お受けできない）を、冒頭近くではっきり書く。
4. 理由を一文で添える。詳しすぎる言い訳は避ける。
5. 代案があれば添える。無ければ、今後への含みを持たせる。
6. お詫びの一言で結ぶ。

## 出力形式
```
件名：Re: {件名}（お返事）
{宛名}様
（感謝）
（お断りの結論）
（理由・代案）
（結び）
```

## 例
入力：「取引先から納期2週間の急ぎの依頼。人手が足りず受けられない。再来月なら可能」
出力のポイント：
- 「ご依頼いただき、誠にありがとうございます。誠に申し訳ございませんが、今回はお受けすることが難しい状況です」
- 代案：「再来月以降でしたら対応が可能です」。

## 注意
- 入力に無い理由を作らない。事実に反する言い訳は書かない。
- 断る理由が個人的・感情的なものなら、書かず「諸事情により」とする案も示す。
