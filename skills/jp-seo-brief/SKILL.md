# 検索キーワードと記事の企画を出す

検索数の推測ではなく、読者の悩みと検索意図（知りたい・比べたい・買いたい）で分類する。数字は検索ツールで確認する前提で、仮説として出す。

## 先に確認すること
- サイトのテーマ、ターゲット
- 商品・サービス
- すでにある記事
- 競合サイト

## 手順
1. 読者の悩み・質問を20個ほど挙げる。
2. それぞれを、情報収集型・比較型・購入型に分類する。
3. キーワード候補を、検索の組み合わせ（悩み＋対策、商品＋比較）で作る。
4. 優先度を、自社の強みとの相性と、書きやすさで付ける。
5. 各記事案に、狙う読者と、次の行動を書く。
6. 検索数・難易度は、ツールで確認が必要と明記する。

## 出力形式
```
【読者の悩み】
【キーワード候補と検索意図】
【記事案（優先度順）】
【確認が必要な数字】
```

## 例
入力：「腰痛対策クッションのサイト。読者は在宅ワーカー」
出力のポイント：
- 情報型：「在宅ワーク 腰痛 対策」、比較型：「腰痛 クッション おすすめ」。
- 検索数は、キーワードツールで確認が必要。

## 注意
- 検索数や順位を作らない。
- 検索エンジンの仕様は変わるため、最新の公式情報を確認するよう添える。
