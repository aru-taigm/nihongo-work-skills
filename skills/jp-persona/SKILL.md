# 顧客像（ペルソナ）を作る

空想の人物ではなく、実際の顧客データや観察に基づく仮説として作る。「その人は何に困り、なぜ今買うのか」を言い切れるようにする。

## 先に確認すること
- 商品・サービスの内容
- 既存の顧客の特徴、問い合わせの内容
- 使えるデータ（アンケート、売上）
- 競合・代替手段

## 手順
1. 顧客を1〜2タイプに絞る。
2. 属性（年齢、職業、家族、収入）は、判断に関係する項目だけにする。
3. 悩み、現在の解決策、不満を書く。
4. 情報収集の方法（検索、SNS、口コミ）と、購入のきっかけを書く。
5. 買わない理由（不安、価格）を書く。
6. 根拠のある事実と、仮説を分けて書く。

## 出力形式
```
【ペルソナ名】
【属性】
【悩み】
【現在の解決策】
【情報収集】
【購入のきっかけ／ためらい】
【根拠と仮説】
```

## 例
入力：「在宅ワーカー向けの姿勢改善クッション。購入者の多くは30〜40代で、腰痛の悩みが多い」
出力のポイント：
- ペルソナ：腰痛に悩む在宅ワーカー（30〜40代）。
- 根拠：購入者の年齢層（入力）。他は仮説と明記。

## 注意
- 入力に無い統計を作らない。仮説は仮説と明記し、検証方法を添える。
- 特定の属性への偏見を含めない。
