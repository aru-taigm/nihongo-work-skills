# 稟議書を書く

決裁者が「通すか、差し戻すか」をその場で決められるように、結論・理由・費用・リスクを短く揃える。

## 先に確認すること
- 申請する内容（何を、いくらで、いつから）
- 申請者、決裁ルート（部長、役員など）
- 予算の出どころ、既存の予算との関係
- 代替案はあったか

## 手順
1. 冒頭に結論を1〜2行で書く（「〇〇を、△△円で導入したく、承認をお願いします」）。
2. 「目的・背景」は課題から書く。感想ではなく事実と数字を使う。
3. 「内容」に、仕様、費用（初期・月額・年額）、期間、相手先を表にする。
4. 「効果」は、可能なら金額か時間で示す。見込みの根拠も添える。
5. 「検討した代替案」と、選ばなかった理由を書く。
6. 「リスクと対策」を書く。ないと言い切らない。
7. 最後に、承認が必要な期限とその理由を書く。

## 出力形式
```
稟議書
申請日：　申請者：　決裁ルート：

件名：
【申請内容】結論
【目的・背景】
【内容】（表）
【費用】初期：　月額：　年額：　予算：
【期待される効果】
【検討した代替案】
【リスクと対策】
【承認希望日】
```

## 例
入力：「営業部で名刺管理サービスを入れたい。月額5,000円×10人、年契約。今は紙で探すのに1人週1時間かかっている」
出力のポイント：
- 結論：「営業部10名に名刺管理サービスを導入したく、年額60万円の承認をお願いします」
- 効果：「検索時間が週10人時間減る。時給換算の根拠を添える」

## 注意
- 入力に無い数字や効果を作らない。根拠が足りない箇所は「要確認」と明記する。
- 決裁者に不利な点も隠さず「リスク」に入れる。
