# 催促のメールを書く

相手が忙しいだけの可能性を残しつつ、必要な行動と期限を明確にする。段階（初回・再送・最終）で強さを変える。

## 先に確認すること
- 何を催促するか（返信、入金、書類）と元の期限
- これまでのやりとりの回数と日付
- 相手との関係（取引先、社内、顧客）
- 返答がない場合の次の手段

## 手順
1. 件名に、元の件名と「再送」「お願い」を入れる。
2. 冒頭で、行き違いの可能性に触れる（「すでにご対応済みでしたら、失礼をお許しください」）。
3. 催促する内容と元の期限を、日付で書く。
4. いつまでに、何をしてほしいかを一文で書く。
5. 初回は柔らかく、再送は理由と影響を添え、最終は期限と次の手続きを明記する。
6. 相手が対応しやすいよう、必要な情報（請求書番号、添付）を再掲する。

## 出力形式
```
件名：【再送】{元の件名}のお願い
{宛名}様
（行き違いの断り）
（お願いの内容と期限）
（再掲する情報）
```

## 例
入力：「10日に送った見積書の返事が来ない。来週中に返事がほしい。相手は取引先の鈴木さん」
出力のポイント：
- 初回：「先日お送りした見積書について、ご確認状況を伺います。恐れ入りますが、○日までにご返信いただけますでしょうか」。
- 行き違いの断りを冒頭に置く。

## 注意
- 入力に無い脅し、法的措置、延滞金に触れない。
- 支払いの督促で法的な話をする場合は、専門家に確認するよう添える。
