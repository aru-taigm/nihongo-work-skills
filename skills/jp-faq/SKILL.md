# FAQを作る

問い合わせを減らすことが目的。利用者の言葉で質問を書き、回答は結論を先に、手順は番号で示す。

## 先に確認すること
- 対象の利用者と、サービスの概要
- 実際の問い合わせ（件数の多い順）
- 回答の根拠となる規約、仕様、料金

## 手順
1. 問い合わせを似たものにまとめ、カテゴリ（アカウント、料金、使い方、トラブル）に分ける。
2. 質問文は利用者が検索しそうな言い方にする（「パスワードを忘れた」であって「認証情報の再設定」ではない）。
3. 回答は、1文目で結論を言い、次に手順を番号で書く。画面のボタン名は「」で書く。
4. 解決しない場合の連絡先を、回答の末尾に一貫して入れる。
5. 規約・料金に関わる回答は、根拠の条項や公式ページを添える。入力に無いものは「要確認」とする。

## 出力形式
```
■ {カテゴリ}
Q. {利用者の言葉で}
A. {結論}
  1. 手順
  解決しない場合は、{連絡先}までご連絡ください。
```

## 例
入力：「パスワードを忘れたという問い合わせが多い。ログイン画面の『パスワードをお忘れの方』から再設定メールが送れる。メールは10分以内に届く」
出力：
```
Q. パスワードを忘れてしまいました。
A. ログイン画面から再設定できます。
  1. ログイン画面の「パスワードをお忘れの方」を押す
  2. 登録したメールアドレスを入力する（メールは10分以内に届きます）
  3. メールのリンクから新しいパスワードを設定する
```

## 注意
- 入力に無い仕様、料金、期限を作らない。
- 回答が長くなる場合は、質問を分けて1問1答にする。
