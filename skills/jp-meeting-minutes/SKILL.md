# 議事録を作る

読む人が「何が決まって、誰が何をいつまでにやるか」を30秒で掴める議事録にする。発言の逐語録ではない。

## 先に確認すること
次が入力から読み取れなければ、作る前に短く聞く。分からないまま埋めない。
- 日時、場所（またはオンライン）、参加者
- 会議の目的
- 次回の予定

## 手順
1. 入力から「決定事項」「ToDo（担当・期限）」「保留・未決」「共有事項」を拾い分ける。
2. 担当者と期限が書かれていないToDoは、推測で補わず「担当：未定」「期限：未定」と書く。
3. 議論の経緯は、決定の理由として必要な範囲だけ1〜2行に残す。
4. 数字、固有名詞、日付は入力どおりに写す。言い換えない。
5. 敬体（です・ます）ではなく常体（だ・である）か、体言止めの簡潔な書き方に統一する。

## 出力形式
```
# 議事録：{会議名}
- 日時：
- 場所：
- 参加者：
- 目的：

## 決定事項
1.

## ToDo
| 内容 | 担当 | 期限 |
|---|---|---|

## 保留・未決
-

## 共有事項
-

## 次回
-
```

## 例
入力：
```
5/12 営業定例 田中・佐藤・鈴木 / 新価格表は6月から。田中さんが顧客へ周知、5/31まで。
値引き幅は結論出ず、次回持ち越し。佐藤さんが他社の相場を調べる。
```
出力：
```
# 議事録：営業定例
- 日時：5月12日
- 参加者：田中、佐藤、鈴木

## 決定事項
1. 新価格表を6月から適用する。

## ToDo
| 内容 | 担当 | 期限 |
|---|---|---|
| 新価格表を顧客へ周知する | 田中 | 5月31日 |
| 他社の値引き相場を調べる | 佐藤 | 次回まで |

## 保留・未決
- 値引き幅（次回に持ち越し）
```

## 注意
- 入力に無い出席者、数字、決定を作らない。
- 個人への批判や雑談は載せない。残すべきか迷うものは、確認用に末尾へ分けて示す。
