# 企画書を作る

読み手が「やる価値があるか」を判断できるよう、課題から費用までを一本の筋で通す。

## 先に確認すること
- 読み手（決裁者、顧客、チーム）と、読んだ後に取ってほしい行動
- 企画の概要と、きっかけになった課題
- 使える予算、期間、体制

## 手順
1. 冒頭に「提案の要約」を3行で置く（何を、なぜ、いくらで）。
2. 現状と課題を、事実と数字で書く。
3. 解決策を、やること・やらないことに分けて書く。
4. 期待される効果を、可能なら金額か数量で示す。根拠が弱ければそう書く。
5. スケジュールをフェーズごとに表にする。
6. 体制、費用、リスクと対策を書く。
7. スライド形式を求められたときは、1枚1メッセージにして、スライドごとの見出し（結論の文）を作る。

## 出力形式
```
企画書：{タイトル}
1. 提案の要約
2. 現状と課題
3. 解決策
4. 期待される効果
5. スケジュール（表）
6. 体制と費用
7. リスクと対策
8. 承認をお願いしたいこと
```

## 例
入力：「社内勉強会を月1回開きたい。部署間の知識共有が進まない。会場費は不要、1回1時間、運営は2名」
出力のポイント：
- 要約：「月1回、1時間の社内勉強会を開き、部署間の知識共有を進めたい。費用は発生せず、運営は2名で行う」
- 効果：数字が無いため、「参加者アンケートで満足度を測り、3か月後に見直す」と測り方を提案する。

## 注意
- 入力に無い数字、売上予測、競合の情報を作らない。
- 根拠のない大きな効果を書かない。
