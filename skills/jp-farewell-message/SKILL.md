# 送別・異動のメッセージを書く

感謝を、具体的な場面とセットで伝える。「寂しい」ばかりでなく、新しい場での活躍を願う。

## 先に確認すること
- 相手との関係、一緒に働いた期間
- 手段（寄せ書き、メール、手紙、スピーチ）
- 思い出の場面、助けてもらったこと
- 相手の次の進路（公表されている範囲）

## 手順
1. 感謝を冒頭に書く。
2. 具体的な場面を一つ書く（「去年の締め切り前に、残って一緒に直してくれた」）。
3. 相手の長所を、その場面から一言で表す。
4. 新しい場所での活躍を願う。
5. 寄せ書きなら1〜2文、メールなら150〜300字に収める。
6. 退職理由に触れない。

## 出力形式
```
{宛名}さんへ
（感謝）
（思い出の場面）
（これからへの願い）
{差出人}
```

## 例
入力：「一緒に4年働いた先輩が転職する。入社したとき資料の作り方を教えてもらった。メールで」
出力のポイント：
- 「入社したばかりの頃に、資料の作り方を一から教えていただいたことを、今でも覚えています」
- 新天地でのご活躍を願う一文で結ぶ。

## 注意
- 入力に無い退職理由・転職先を書かない。
- ネガティブな表現（辞める、去る）を避けるか、言い換える。
