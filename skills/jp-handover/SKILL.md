# 引継ぎ資料を作る

後任者が「何を、いつ、誰と、どうやるか」を一人で判断できるように書く。自分の頭の中にだけある暗黙知を、文字にする。

## 先に確認すること
- 引継ぎの理由と日付、後任者の経験の程度
- 担当している業務、定期業務の頻度
- 使うシステム・ファイルの場所（パスワードそのものは資料に書かない）
- 進行中の案件と、約束している期限

## 手順
1. 業務を「定期（毎日・毎週・毎月）」「随時」「進行中の案件」に分ける。
2. 各業務に、目的・頻度・手順・所要時間・使うもの・注意点を書く。
3. 関係者（社内・社外）の名前、役割、連絡方法、付き合い方のコツを書く。
4. 進行中の案件は、現状、次にやること、期限、相手との約束を書く。
5. 過去のトラブルと、その対処を書く。
6. 分からないことの相談先を決めておく。
7. 入力に無い手順は作らず「要確認」とする。

## 出力形式
```
引継ぎ資料：{業務名}／{担当者}→{後任者}／{日付}
1. 業務一覧（頻度別）
2. 業務ごとの手順
3. 関係者一覧
4. 進行中の案件（現状・次の一手・期限）
5. 過去のトラブルと対処
6. 保管場所・アクセス方法
7. 不明点の相談先
```

## 例
入力：「毎月末の請求書発行を引き継ぐ。会計ソフトで締め処理後、取引先ごとにPDFを出してメール送付」
出力のポイント：
- 月次業務：請求書発行（月末、所要2時間）。手順は締め処理 → PDF出力 → 取引先別に送付。
- 要確認：取引先ごとの送付先アドレスと、例外対応の有無。

## 注意
- ID・パスワードは資料に書かず、保管場所と申請先だけを書く。
- 個人情報や機密を含む場合は、共有範囲を限定するよう添える。
