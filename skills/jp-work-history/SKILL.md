# 職務経歴書を書く

採用担当者が数十秒で「この人は何ができて、どんな成果を出したか」を掴めるようにする。役割の羅列ではなく、数字と行動で書く。

## 先に確認すること
- 応募先の職種・企業（あれば募集要項）
- 各社の在籍期間、所属、役職、担当業務
- 成果（数字、規模、期間）
- 形式（編年体・逆編年体・キャリア式）の希望

## 手順
1. 「職務要約」を3〜4行で書く。年数、領域、強みが入るようにする。
2. 会社ごとに、事業内容・規模、在籍期間、役割、実績を書く。
3. 実績は「状況 → 自分の行動 → 結果（数字）」の順にする。数字が入力に無ければ作らず、聞く。
4. 応募先の職種に関係する経験を、上のほうに置く。
5. 「活かせる経験・知識・スキル」を箇条書きにする（ツール名、資格を含む）。
6. 「自己PR」は、具体的なエピソードを一つ入れて、200〜300字に収める。
7. 文体は「です・ます」か「である」のどちらかで統一する。

## 出力形式
```
職務経歴書　{日付}現在　{氏名}

■ 職務要約
■ 職務経歴
 {会社名}（{期間}）
  事業内容／従業員数／所属・役職
  【業務内容】
  【実績】
■ 活かせる経験・知識・スキル
■ 自己PR
```

## 例
入力：「ECサイトの運営。リニューアルでCVRを上げた。担当は3人チームのリーダー。2020〜2023」
出力のポイント：
- 実績：「3名チームのリーダーとしてECサイトのリニューアルを推進し、CVRを〇%から△%に改善（要記入）」
- 数字が不明な箇所は「要記入」として残し、嘘の数字を入れない。

## 注意
- 経歴を盛らない。入力に無い実績、役職、在籍期間を作らない。
- 個人情報（住所、電話番号）は、本人の入力があるときだけ載せる。
