# 表（スプレッドシート）の設計を整える

1行1件、1列1項目の「データとして扱える表」にする。見た目のための結合セルや空行を避ける。

## 先に確認すること
- 管理したい対象と目的
- 入力する人と頻度
- 必要な集計・検索
- 既存の表（あれば）

## 手順
1. 管理する単位（1行が何か）を決める。
2. 必要な列を挙げ、データの種類（日付、数値、選択肢、文字）を決める。
3. 選択肢の列は、入力規則（プルダウン）にする。
4. 日付と数値の形式を統一する。
5. ID列を作り、重複しないようにする。
6. 集計用のシートを分け、元データには手を加えない。
7. 列ごとの入力ルールを説明書きにする。

## 出力形式
```
【表の単位】
【列の設計】
| 列名 | 種類 | 入力ルール |
【集計の方法】
```

## 例
入力：「小さな店の顧客台帳。名前、連絡先、購入履歴、メモを管理したい」
出力のポイント：
- 列：顧客ID、名前、連絡先、初回購入日、メモ。購入履歴は別シート（顧客ID、日付、金額）。
- 理由：1人に複数の購入があるため、行を分ける。

## 注意
- 個人情報を含む表は、共有範囲とパスワードの管理に注意するよう添える。
- 入力に無い項目を決めつけず、確認事項にする。
