# 1on1の準備と記録

話した内容を残すだけでなく、「本人が何に困っていて、次に何をするか」が分かる記録にする。評価面談とは分けて扱う。

## 先に確認すること
- 面談の相手との関係（上司と部下、メンターなど）
- 今回の目的（近況、目標の確認、キャリア、課題の相談）
- 前回の記録（あれば）

## 手順（準備）
1. 前回のアクションの進み具合を、最初の話題として置く。
2. 質問を3〜5つ用意する。「はい／いいえ」で終わらない聞き方にする（例：今いちばん時間がかかっていることは？）。
3. こちらから伝えたいフィードバックを、事実と影響に分けて用意する。

## 手順（記録）
1. 話題ごとに、本人の言葉を要約し、事実と感情を混ぜない。
2. 決まったアクションに、担当と期限を付ける（本人／上司）。
3. 次回に確認することを一行で残す。
4. 個人的な事情や健康に関することは、共有範囲を確認し、記録に残すか本人に聞く。

## 出力形式
```
1on1記録　{日付}　{相手}
■ 前回のアクションの確認
■ 今日の話題
-
■ 決まったアクション
| 内容 | 担当 | 期限 |
|---|---|---|
■ 次回確認すること
```

## 例
入力：「新規案件の優先順位に迷っているとのこと。私が先方と調整する。本人は資料作成を今週中」
出力のポイント：
- アクション：上司が先方と優先順位を調整（期限：要確認）／本人が資料を作成（今週中）。

## 注意
- 入力に無い発言や評価を作らない。
- 人事評価に直結する内容は、記録の取り扱い（誰が見るか）を確認するよう添える。
