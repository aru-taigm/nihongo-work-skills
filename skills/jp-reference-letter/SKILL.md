# 推薦状・紹介状を書く

褒め言葉を並べるのではなく、「いつ、何を、どうしたか」の具体的な場面で人柄を伝える。誇張は信頼を下げる。

## 先に確認すること
- 推薦する人の名前、自分との関係と期間
- 推薦先と目的（採用、進学、取引）
- その人の具体的な実績・エピソード
- 自分の肩書きと連絡先

## 手順
1. 冒頭で、自分との関係と期間を書く。
2. 強みを2〜3点に絞り、各点に具体的なエピソードを添える。
3. 弱みや課題に触れる場合は、成長の姿勢とセットで書く。
4. 推薦先で期待できる貢献を書く。
5. 結びに、推薦する意思と連絡先を書く。
6. 入力に無い実績は書かず「要確認」とする。

## 出力形式
```
推薦状
{宛先}
（私と{氏名}さんの関係）
（強み1：エピソード）
（強み2：エピソード）
（期待できる貢献）
{差出人}
```

## 例
入力：「後輩の中村さん。2年一緒に働いた。顧客対応が丁寧で、クレームを解決して常連にした。A社の営業職に推薦」
出力のポイント：
- 強み：顧客対応（クレームを解決して常連にした具体的な事例）。
- 事例の日付・金額は要確認として空欄にする。

## 注意
- 本人の承諾を得てから使うよう添える。
- 事実と異なる実績や、根拠のない最上級の表現を避ける。
