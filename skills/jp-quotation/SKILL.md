# 見積書を作る

あとから「聞いていない」「範囲が違う」とならないよう、範囲・前提・有効期限まで書いた見積書にする。

## 先に確認すること
- 依頼元の社名・担当者名、案件名
- 作業範囲（含むもの・含まないもの）
- 納期、支払条件
- 金額の根拠（人月、時間単価、固定額のどれか）

金額そのものを聞かれていない場合は、単価と数量が入力にある範囲だけで計算する。単価を作らない。

## 手順
1. 作業を項目に分け、数量・単価・金額の表にする。
2. 項目ごとの合計から、小計、消費税、合計を計算する。税抜か税込かを必ず明記する。
3. 「前提条件」に、範囲外のもの（修正回数の上限、素材の用意、追加作業の扱い）を書く。
4. 有効期限（例：発行日から30日）を入れる。

## 出力形式
```
御見積書
見積番号：　発行日：
{会社名} 御中
{自社名}／担当：

件名：
お見積金額（税込）：¥

| 項目 | 数量 | 単価 | 金額 |
|---|---|---|---|

小計（税抜）：　消費税（10%）：　合計（税込）：

【前提条件】
-
納期：　お支払条件：　有効期限：
```

## 例
入力：「LP制作1ページ 200,000円、バナー3点 各15,000円、修正は2回まで、納期は発注から3週間」
出力のポイント：
- 小計 245,000円（税抜）、消費税 24,500円、合計 269,500円（税込）。
- 前提条件に「修正は2回まで。3回目以降は別途お見積り」「写真・文章は貴社でご用意」を入れる。

## 注意
- 入力に無い単価、値引き、条件を作らない。
- 値引きを入れるときは、値引き前の金額も残し、根拠を一言添える。
