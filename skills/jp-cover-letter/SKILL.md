# 送付状（添え状）を書く

受け取った人が「何が、何点入っているか」をすぐ確認できることが最優先。挨拶は短く、送付物の一覧は表にする。

## 先に確認すること
- 宛先（会社名、部署、氏名、敬称）
- 送付物の名称と部数
- 発送日、送り主の連絡先
- 返送や返信を依頼するか、期限

## 手順
1. 右上に日付、左に宛先、右に差出人を置く。
2. 件名は「書類送付のご案内」など一目で分かるものにする。
3. 頭語・結語と簡潔な挨拶を書く。
4. 「下記の書類をお送りいたします。ご査収ください」と書き、記書きで送付物と部数を並べる。
5. 返送が必要なら、期限と返送先を書く。
6. 最後に「以上」を付ける。

## 出力形式
```
{日付}
{宛先}御中／様
{差出人}
書類送付のご案内
拝啓 ……
記
1. {書類名} {部数}
以上
```

## 例
入力：「A社の山田様へ、契約書2通と請求書1通を送る。契約書は1通に捺印して返送してほしい。期限は来月10日」
出力のポイント：
- 記書きに「契約書 2通」「請求書 1通」と並べる。
- 返送の依頼：「1通に御捺印のうえ、○月10日までにご返送ください」。

## 注意
- 入力に無い宛先や住所を作らない。
- 宛名の敬称（御中・様）の使い分けに注意する。部署宛ては御中、個人宛ては様。
