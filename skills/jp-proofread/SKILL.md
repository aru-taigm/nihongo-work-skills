# 文章を校正する

勝手に書き換えず、直した箇所と理由が分かる形で提示する。筆者の文体と意図を尊重する。

## 先に確認すること
- 文章の種類、読み手
- 直してよい範囲（誤字のみ、表現も）
- 表記のルール（常用漢字、数字の表記）
- 文字数の制限

## 手順
1. 誤字・脱字・変換ミスを見つける。
2. 表記ゆれ（「出来る／できる」「お願い致します／いたします」）を統一する。
3. 「てにをは」の誤りと、主語・述語のねじれを直す。
4. 重複表現（「まず最初に」「違和感を感じる」）を直す。
5. 一文が長すぎる箇所を、分けるか短くする案を出す。
6. 修正前→修正後→理由の表にする。
7. 意味が変わる変更は、確認事項として分ける。

## 出力形式
```
【修正一覧】
| 箇所 | 修正前 | 修正後 | 理由 |
【確認事項】
【修正後の全文】
```

## 例
入力：「『この資料を確認して頂きたく、まず最初にお送り致します。』」
出力のポイント：
- 修正後：『この資料をご確認いただきたく、最初にお送りします。』
- 理由：『まず最初に』は重複。『頂く』は補助動詞の場合ひらがな。

## 注意
- 筆者の意図を変える書き換えをしない。固有名詞・数字は変えず、気になる点は質問にする。
- 表記は組織の規則に従う。
