# プライバシーポリシーの下書きを作る

ひな形の穴を埋めるのではなく、サイトが実際に取得する情報と使い方に合わせて書く。法的な判断は専門家に任せる前提で、論点の漏れを防ぐ。

## 先に確認すること
- 事業者名、連絡先
- 取得する個人情報（氏名、メール、Cookie、アクセス解析など）
- 利用目的
- 第三者提供・委託・外国への移転の有無
- 解析ツールや広告の利用

## 手順
1. 事業者の名称と連絡先を書く。
2. 取得する情報の種類を一覧にする。
3. 利用目的を、できるだけ具体的に書く。
4. 第三者提供・委託の有無と、相手の範囲を書く。
5. Cookie、アクセス解析、広告配信などを使う場合は、その旨と無効化の方法を書く。
6. 開示・訂正・削除の請求の窓口と手続きを書く。
7. 改定の方法と日付を書く。
8. 入力に無い項目は「要確認」とする。

## 出力形式
```
プライバシーポリシー
1. 事業者
2. 取得する情報
3. 利用目的
4. 第三者提供・委託
5. Cookie・解析ツール
6. 開示等の請求
7. 改定
```

## 例
入力：「個人開発のWebアプリ。メールアドレスだけ取得。Google Analyticsを使っている。広告は無し」
出力のポイント：
- 取得：メールアドレス。利用目的：ログインと連絡。解析：Google Analyticsの利用と、無効化の方法。
- 第三者提供の有無は「要確認」とする。

## 注意
- この下書きは法的な助言ではない。公開前に、個人情報保護法などの最新の規定と照らして専門家に確認するよう必ず添える。
- 入力に無い取得項目を作らない。
