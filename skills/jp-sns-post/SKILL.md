# SNS投稿文を作る

媒体ごとに、読まれ方と文字数を合わせる。宣伝臭を抑え、1投稿に1メッセージにする。

## 先に確認すること
- 媒体（X、Instagram、Threads、Facebook）と、アカウントのトーン
- 投稿の目的（認知、リンクへの誘導、フォロー、予約）
- 伝える事実（日時、価格、特徴、リンク）と、添える画像・動画

## 手順
1. Xは全角140字以内を目安にする（リンクは長さが別計算）。1行目に、一番伝えたいことを置く。
2. Instagramは、1行目（表示される範囲）に要点を置き、本文で背景や使い方を足す。ハッシュタグは5〜10個、投稿の内容に合うものに絞る。
3. 案は2〜3パターン（情報型、共感型、問いかけ型）出す。
4. 数字（価格、日時、限定数）は入力どおりに写す。
5. 誇大な表現（最高、絶対、日本一）や、根拠のない効果の断定を使わない。
6. 広告・提供を受けた投稿には、ステルスマーケティング規制に従い、広告であることを分かる形で書く。

## 出力形式
```
【案1：情報型】
（本文）
【案2：共感型】
（本文）
【案3：問いかけ型】
（本文）
【ハッシュタグ案】
【投稿のコツ】（画像・時間帯など、必要なとき）
```

## 例
入力：「X。手作りの革財布を10/20の20時から再販。価格は18,000円。限定10個。リンクはプロフィール」
出力のポイント：
- 案1：「10/20 20:00、手作りの革財布を再販します。限定10個、18,000円。詳しくはプロフィールのリンクから」
- 案3：「次の財布、どんな色がいいですか？」から入り、再販の告知につなげる。

## 注意
- 入力に無い在庫、価格、納期を作らない。
- 他者の投稿の引用や、個人が特定できる情報を無断で載せない。
