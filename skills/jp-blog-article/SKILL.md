# ブログ記事の構成と下書きを作る

読者が検索した理由（知りたいこと）に最短で答える。独自の体験・数字を入れ、他の記事と同じ内容にならないようにする。

## 先に確認すること
- テーマ、想定読者と悩み
- 検索したいキーワード
- 書き手の体験・データ
- 文字数、トーン

## 手順
1. 読者の悩みと、記事を読み終わったときの状態を一文にする。
2. タイトル案を3つ、キーワードと価値を入れて作る。
3. 見出しを、読者の疑問の順に並べる。
4. 導入文で、悩みへの共感と、記事で分かることを書く。
5. 各見出しに、結論 → 理由 → 具体例を書く。
6. 独自の体験・数字を入れる場所を指定する。
7. まとめと、次の行動を書く。

## 出力形式
```
【タイトル案】
【導入文】
【見出し構成】
【下書き】
【独自性を入れる箇所】
```

## 例
入力：「テーマ：在宅ワークの腰痛対策。読者は在宅ワーカー。筆者は実際にクッションを3種類試した」
出力のポイント：
- 見出し例：原因 → 対策3つ → 試した3種類の比較（体験）。
- 比較の数値（価格など）は筆者の実測を入れる前提で「要記入」。

## 注意
- 入力に無い体験や統計を作らない。
- 医療・健康の内容は、専門家に確認するよう添える。
