# 時候の挨拶・挨拶状を書く

季節と時期に合った型を使い、短く誠実にまとめる。時期を誤ると失礼になるため、日付を確認してから書く。

## 先に確認すること
- 送る日付（時期によって表現が変わる）
- 相手との関係（取引先、顧客、恩師、社内）
- 用途（年賀状、寒中見舞い、暑中見舞い、メールの書き出し）
- 先方に喪中の連絡があったか

## 手順
1. 時期を判断する。
   - 年賀状：元日〜1月7日（松の内）に届くように。1月8日〜立春（2月4日ごろ）は「寒中見舞い」。
   - 暑中見舞い：小暑（7月上旬）〜立秋（8月7日ごろ）の前。立秋以降は「残暑見舞い」。
2. 先方が喪中なら、年賀状は避け、寒中見舞いにする。
3. 年賀状は、新年の挨拶、旧年の感謝、今後のお願い、一言の近況の順にする。賀詞（謹賀新年）と「去年」「去る」などの忌み言葉の言い換え（「昨年」）に注意する。
4. メールの書き出しは「時下ますますご清栄のこととお慶び申し上げます」など。時候の挨拶（例：晩秋の候）は硬いので、親しい関係では「朝晩冷え込む季節になりましたが」のように柔らかくする。
5. 結びは、相手の健康と繁栄を祈る言葉で終える。

## 出力形式
```
（賀詞／時候の挨拶）
（感謝）
（近況・今後のお願い）
（結び）
日付　差出人
```

## 例
入力：「取引先への年賀状。昨年は新商品でお世話になった。今年も協力して市場を広げたい」
出力のポイント：
- 「謹んで新春のお慶びを申し上げます。昨年は新商品の発売に格別のご協力を賜り、厚く御礼申し上げます」
- 「本年もより良い関係を築けるよう努めてまいります。何卒よろしくお願い申し上げます」

## 注意
- 入力に無い出来事や数字を作らない。
- 年賀状では「賀正」「迎春」など短い賀詞を目上の人に使わない（敬意が十分でないとされる）。
