# 和英・英和のビジネス翻訳

直訳ではなく、読み手が自然に受け取れる文章にする。日本語の敬語や遠回しな表現は、英語では丁寧で明確な依頼に置き換える。

## 先に確認すること
- 相手との関係（初めて、顧客、同僚）と、トーン（フォーマル／カジュアル）
- 目的（依頼、報告、お断り、お詫びなど）
- 固有名詞や用語集（社名、製品名、決まった訳語）

## 手順（日本語 → 英語）
1. 日本語の「ご検討いただけますと幸いです」「よろしくお願いします」のような決まり文句は、目的に応じて英語の自然な表現に変える（例：Could you please …? / I would appreciate it if …）。
2. 主語を補う。日本語は主語を省くため、誰がするのかを明確にする。
3. 期限や数字は、日付形式を英語圏に合わせる（May 12, 2026）。通貨と単位も明記する。
4. あいまいな「検討します」は、実際の意図（前向きに検討、見送りの婉曲）を確認して訳す。

## 手順（英語 → 日本語）
1. 直接的な表現を、日本のビジネス文書に合う丁寧さに調整する。
2. 受動・使役の連続を避け、主語と述語を近づける。
3. 数字、固有名詞、日付は原文どおりに残す。

## 出力形式
```
【訳文】
（本文）

【訳の判断メモ】（必要なときだけ）
- 「〇〇」は△△と訳した。理由：
- 確認したい点：
```

## 例
入力：
```
お忙しいところ恐縮ですが、ご確認のほどよろしくお願いいたします。（期限：金曜日）
```
出力：
```
【訳文】
I know you are busy, but could you please review this by Friday?

【訳の判断メモ】
- 「恐縮ですが」は、"I know you are busy, but" で依頼の前置きにした。
- 「ご確認のほどよろしく」は "could you please review" と、して欲しい行動を明確にした。
- 期限を "by Friday" と具体的に書いた。日付が決まっていれば "by Friday, May 15" とする。
```

## 注意
- 原文に無い情報（期限、金額、約束）を足さない。
- 法律文書、契約書、医療文書は、翻訳後に専門家の確認が必要だと添える。
