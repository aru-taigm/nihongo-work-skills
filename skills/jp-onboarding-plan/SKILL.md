# 新人・中途の受け入れ計画を作る

最初の1週間で「安心して質問できる関係」を作り、3か月で一人で任せられる範囲を明確にする。

## 先に確認すること
- 入社者の職種と経験
- 受け入れ担当（上司、メンター）
- 配属先で最初に任せたい仕事
- 準備が必要なもの（PC、アカウント、席）

## 手順
1. 入社前の準備（PC、アカウント、座席、歓迎の連絡）を一覧にする。
2. 初日：挨拶、オフィス案内、ルール説明、メンターとの昼食を入れる。
3. 1週間：会社と仕事の全体像、関係者との面談、簡単な業務を入れる。
4. 1か月・3か月：任せる業務と、面談（振り返り）の日程を入れる。
5. 各項目に担当者と期限を付ける。
6. 入社者が確認できるチェックリストも添える。

## 出力形式
```
【入社前の準備】
【初日】
【1週間】
【1か月】
【3か月】
（各項目：内容／担当／期限）
```

## 例
入力：「4月1日に営業の中途入社が来る。経験者。メンターは佐藤さん」
出力のポイント：
- 入社前：PC・アカウント・座席の準備（担当：総務、3月末）。
- 初日：午前に会社説明、昼にメンターと昼食、午後に担当顧客の引継ぎ資料の説明。

## 注意
- 入力に無い人名・日程を作らず、「要記入」とする。
- 労務手続き（社会保険など）は、人事の担当に確認するよう添える。
