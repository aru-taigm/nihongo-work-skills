# 商談・打ち合わせの準備をする

「今日のゴール」を決め、そこから逆算して話す順番と質問を作る。調べれば分かることで時間を使わない。

## 先に確認すること
- 相手（会社、担当者）と、これまでの経緯
- 今日の目的と、取りたい合意
- 手元の資料・数字
- 相手が気にしそうなこと

## 手順
1. 今日のゴール（取りたい合意・次の約束）を一文にする。
2. 相手の状況（事業、課題、決裁者）を整理し、不明な点は質問にする。
3. 話す順番（挨拶 → 目的の確認 → 提案 → 質問 → 次の約束）を決める。
4. 想定される質問・反論と、答えを用意する。
5. 持ち物（資料、見積り、名刺）を確認する。
6. 終わった後にやること（お礼、議事録）を決める。

## 出力形式
```
【ゴール】
【相手の状況】
【進行案】
【質問リスト】
【想定問答】
【持ち物】
【終了後】
```

## 例
入力：「明日、A社の部長に新サービスを提案する。前回は担当者と話しただけ。価格が気になっていそう」
出力のポイント：
- ゴール：次回に見積りを出す約束を取る。
- 想定反論：価格が高い → 費用対効果の数字（要記入）で答える。

## 注意
- 入力に無い相手の情報を作らず、不明点は質問にする。
- 相手の個人情報をむやみに調べない。
