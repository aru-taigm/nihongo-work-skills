# 交渉・価格相談の準備をする

勝ち負けではなく、双方が合意できる範囲を見つける。最も良い条件と最低限の条件、決裂したときの代案をあらかじめ決める。

## 先に確認すること
- 交渉の内容と相手
- こちらの希望と最低ライン
- 相手の事情・関心
- 決裂時の代案（他の取引先など）

## 手順
1. 目的と、最も良い条件・最低限の条件を決める。
2. 決裂したときの代案を用意し、強さを評価する。
3. 相手の関心（価格だけでなく、納期、品質、継続）を整理する。
4. 譲れる項目と、譲れない項目を分ける。
5. 提示の順番と、根拠（数字、実績）を決める。
6. 複数の条件を組み合わせた案（価格を下げる代わりに、数量・期間を増やす）を用意する。
7. 合意内容を、文書やメールで確認する。

## 出力形式
```
【目的／最低ライン】
【代案】
【相手の関心】
【進め方】
【合意の確認】
```

## 例
入力：「仕入先に、単価を5%下げてほしい。年間の発注量を増やせる。代わりの仕入先も探している」
出力のポイント：
- 提案：単価5%減と、年間発注量の増加をセットに。
- 代案：代わりの仕入先の見積り（要記入）。

## 注意
- 入力に無い数字・相手の事情を作らない。
- 脅しや嘘、不当な圧力を勧めない。独占禁止法などは、専門家に確認するよう添える。
