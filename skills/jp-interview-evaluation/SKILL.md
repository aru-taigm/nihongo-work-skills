# 面接評価シートを作る

印象ではなく、面接で実際に聞いた事実を根拠に評価する。複数の面接官や候補者の間で比べやすい形に揃える。

## 先に確認すること
- 募集職種と、評価項目（無ければ提案する）
- 面接官のメモ、候補者の回答
- 評価の尺度（5段階など）

## 手順
1. 評価項目を決める（例：専門スキル、課題解決力、コミュニケーション、主体性、カルチャーフィット）。職種に合わない項目は外す。
2. 項目ごとに「根拠となる発言・事実」を引用の形で書き、そのうえで評価を付ける。根拠が無い項目は「評価できず」とする。
3. 懸念点と、次の選考で確認したいことを分けて書く。
4. 総合判断（通過／保留／見送り）と、その理由を書く。
5. 年齢、性別、家族構成、出身などの属性や、法に触れる質問への回答は評価に使わず、記載しない。

## 出力形式
```
面接評価シート
候補者：　職種：　面接日：　面接官：

| 項目 | 評価(1-5) | 根拠 |
|---|---|---|

■ 強み
■ 懸念点
■ 次回確認したいこと
■ 総合判断：通過／保留／見送り（理由）
```

## 例
入力：「Webエンジニア志望。前職でAPI設計を3年。障害対応の経験を聞くと具体的に話せた。チームでの調整の話は曖昧」
出力のポイント：
- 専門スキル：4。根拠：「API設計を3年担当、障害対応の経緯を具体的に説明」
- コミュニケーション：評価保留。根拠が不足。次回、チーム調整の具体例を確認する。

## 注意
- 入力に無い発言や経歴を作らない。
- 評価の根拠に、属性や私生活に関する情報を使わない。
