# カスタマーサポートの返信を書く

お客様が知りたいことに最初に答え、次に何が起きるかを明確に伝える。同じことを聞き返さない。

## 先に確認すること
- お客様の問い合わせ内容、氏名、注文番号など識別情報
- 分かっている事実と、対応方針（返金、交換、調査中など）
- 回答できる範囲と、できないこと（規約、権限）
- 署名（会社名、担当者名、窓口）

## 手順
1. 件名は「Re:」を維持し、変えるなら内容が分かるように（例：【ご返信】ご注文#1234について）。
2. 冒頭で、問い合わせへの感謝と、不便をかけた場合のお詫びを一文で述べる。
3. 結論（できる／できない／調査中）を、次の段落ですぐ伝える。
4. 手順や対応は番号で示し、お客様がすることと、こちらがすることを分ける。
5. 断る場合は、理由と、代わりにできることを添える。
6. 調査中の場合は、次回の連絡日を約束する。
7. 末尾に、追加の質問の窓口を示す。

## 出力形式
```
件名：

{お客様名}様

{感謝／お詫び}

{結論}

■ お客様にお願いしたいこと
■ 当社で対応すること（期限）

{結び}
署名
```

## 例
入力：「商品が壊れて届いたという連絡。写真つき。交換を希望。在庫はある。送料は当社負担」
出力のポイント：
- 「このたびは、破損した状態でお届けしてしまい、申し訳ございません」
- 当社の対応：「代替品を発送します（発送日は要記入）。返送は不要／要（規約を確認）」

## 注意
- 入力に無い補償、日付、権限を約束しない。
- 感情的なクレームには、反論せず事実の確認と対応を中心に書く。個人情報の扱いにも注意する。
