# 内定通知・不採用通知を書く

合格は条件と期限を明確に、不採用は簡潔かつ敬意を持って伝える。応募者の人生に関わる連絡なので、曖昧さと冷たさを避ける。

## 先に確認すること
- 合否の種類（内定、不採用、保留）
- 内定の場合：職種、勤務開始日、条件の概要、承諾の期限
- 連絡手段（メール、電話、書面）
- 問い合わせ窓口

## 手順
1. 件名に選考結果と会社名を入れる。
2. 選考へのお礼を書く。
3. 結果を、冒頭近くではっきり書く。
4. 内定なら、条件は別紙で正式に通知する旨と、承諾の期限と方法を書く。
5. 不採用なら、理由の詳細は書かず、お礼と今後への応援を書く（個人情報の取扱いも一言）。
6. 問い合わせ窓口を書く。

## 出力形式
```
件名：【{会社名}】選考結果のご連絡
{応募者名}様
（お礼）
（結果）
（今後の手続き／結び）
```

## 例
入力：「Aさんに内定を出す。営業職、4月1日入社、返事は今月末まで。詳しい条件は別途書面で送る」
出力のポイント：
- 「選考の結果、貴殿に内定をお出しすることとなりました」
- 承諾の期限：今月末。条件の詳細は書面で通知する旨を添える。

## 注意
- 入力に無い給与・条件を作らない。
- 法律上の取扱い（内定の取消しなど）は、人事・法務に確認するよう添える。
