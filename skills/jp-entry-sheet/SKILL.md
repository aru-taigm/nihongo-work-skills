# 志望動機・自己PR・ガクチカを書く

結論から書き、具体的なエピソードで裏付け、応募先とのつながりを示す。文字数を指定されたら、その範囲に収める。

## 先に確認すること
- 設問の文言と文字数
- 応募先企業・職種、調べて分かっていること（事業、理念、募集要項）
- 本人の経験（エピソード、数字、役割、困難と乗り越え方）

## 手順
1. 設問に直接答える一文を先頭に置く。
2. 志望動機は「なぜこの業界か → なぜこの会社か → 入社後に何をしたいか」の順にする。会社名を差し替えても通る文章は不合格として書き直す。
3. ガクチカ・自己PRは「結論 → 状況・課題 → 自分の行動 → 結果 → 学び」の順にする。
4. 「頑張った」「貢献したい」のような抽象語を減らし、数字や固有の事実に置き換える。
5. 指定の文字数の90〜100%に収める。数えて確認する。
6. 本人が書いた文章の添削では、直した理由を箇条書きで添える。

## 出力形式
```
【設問】（文字数）
（本文）

【文字数】〇字
【書き方のポイント】
-
```

## 例
入力（志望動機の下書き）：
```
御社の理念に共感しました。成長したいです。
```
出力：
```
【直した点】
- 「理念のどこに、自分のどの経験が重なるか」が無い。→ 経験を一つ入れて接続する。
- 「成長したい」は会社への還元が見えない。→ 入社後に任せてほしい仕事まで書く。

【書き直しの骨子】
1. 結論：（職種）として〇〇に貢献したい。
2. 経験：学生時代／前職の△△で、数字つきの成果を一つ。
3. 接続：貴社の「△△」という方針と、その経験が重なる。
4. 入社後：最初に取り組みたい仕事を一つ。
※経験の具体例（役割、数字）をいただければ、本文まで書き上げます。
```

## 注意
- 経験や数字を作らない。足りない材料は質問する。
- 他人の文章の丸写しや、企業の公開情報の言い換えだけの文章を避ける。
