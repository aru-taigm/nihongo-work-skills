# お知らせ・告知文を書く

読む人が「自分に関係あるか」「いつまでに何をすればよいか」を最初の数行で判断できるようにする。

## 先に確認すること
- 読み手（全社員、顧客、取引先）
- 何が、いつから変わるか
- 読み手が取る行動と期限（無ければ「対応不要」と明記）
- 問い合わせ先

## 手順
1. 件名に【お知らせ】【重要】【ご協力のお願い】などの種別と、内容を入れる。重要度が低いものに【重要】を付けない。
2. 冒頭に要点（いつから、何が変わる、読み手がすること）を2〜3行で書く。
3. 背景・理由を短く書く。
4. 日時、対象、手順は箇条書きにする。
5. 期限のある行動は、日付と曜日で書く。
6. 末尾に問い合わせ先を置く。社外向けは、お詫びや感謝の言葉を添える。

## 出力形式
```
件名：【お知らせ】

各位

（要点）

■ 変更の内容
■ 対象
■ お願いしたいこと（期限）
■ 理由・背景
■ 問い合わせ先
```

## 例
入力：「システムメンテナンスで、10/20（日）の22時〜翌2時は社内ポータルが使えない。作業中のデータは前日までに保存してほしい」
出力のポイント：
- 件名：【お知らせ】社内ポータルのメンテナンスについて（10/20 22:00〜翌2:00）
- お願い：10/20（日）の22時までに、作業中のデータを保存してください。

## 注意
- 入力に無い日付、対象、手順を作らない。
- 長くなる場合は、要点だけをメール本文に、詳細は別資料にして案内する。
