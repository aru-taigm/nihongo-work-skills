# 提案依頼書（RFP）・要件整理を作る

受注側が「何を、いつまでに、いくらで」を判断できるよう、目的と要件を分ける。曖昧なまま発注すると、見積りがばらつき、後で揉める。

## 先に確認すること
- 背景と目的（なぜ作るか）
- 対象範囲と、含めないこと
- 予算、納期、体制
- 提案に求めること（見積り、体制、実績）

## 手順
1. 背景と目的を、現状の課題から書く。
2. 要件を「必須」「できれば」に分け、機能と非機能（性能、セキュリティ）に整理する。
3. 範囲外（含めないこと）を明記する。
4. スケジュールと、納品物（成果物）を書く。
5. 提案の評価基準（価格、実績、体制）と、選定の流れを書く。
6. 提案の提出期限と、質問の受付方法を書く。

## 出力形式
```
提案依頼書：{案件名}
1. 背景と目的
2. 要件（必須／任意）
3. 範囲外
4. スケジュール・納品物
5. 予算
6. 提案に求める内容
7. 評価基準・選定の流れ
```

## 例
入力：「予約管理システムを新しくしたい。今は電話と紙。予算は300万円、半年で。スマホから予約できること」
出力のポイント：
- 必須：スマホからの予約、予約の確認・変更・キャンセル。
- 範囲外：決済機能（今回は含めない）。予算・納期は入力のとおり。

## 注意
- 入力に無い予算・要件を作らない。
- 契約・知的財産・秘密保持の条項は、法務に確認するよう添える。
