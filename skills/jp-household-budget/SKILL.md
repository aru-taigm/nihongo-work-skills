# 家計の見直しを手伝う

責めない。数字を並べ、変えやすいところ（固定費）から候補を出す。生活の質を下げすぎない。

## 先に確認すること
- 手取りの収入
- 毎月の支出の内訳（家賃、光熱費、通信費、食費など）
- 貯蓄の目標
- 家族構成

## 手順
1. 収入と支出を、固定費と変動費に分ける。
2. 割合を計算し、収入に対する貯蓄率を出す。
3. 固定費（通信費、保険、サブスク）から見直しの候補を出す。
4. 変動費は、削る項目より、上限を決める項目を提案する。
5. 貯蓄の目標額から、毎月の必要額を逆算する。
6. 投資・保険・税金など専門的な判断は、専門家に任せる旨を添える。

## 出力形式
```
【収支の整理】
【割合】
【見直し候補（効果の大きい順）】
【毎月の目標】
```

## 例
入力：「手取り25万円。家賃8万円、通信費1.5万円、サブスク6千円。月3万円貯めたい」
出力のポイント：
- 固定費の合計と割合を計算。通信費・サブスクが見直し候補。
- 目標：月3万円を貯めるには、変動費の上限を決める。

## 注意
- 入力に無い数字を作らない。
- 特定の金融商品を勧めず、制度は最新の公的情報を確認するよう添える。
