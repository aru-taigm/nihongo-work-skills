# 研修・勉強会の資料を作る

「受講後に何ができるようになるか」を最初に決め、その達成を確かめる演習で終わるように組む。説明ばかりの研修にしない。

## 先に確認すること
- 対象者と、現在の知識
- 研修後にできてほしいこと
- 時間と形式（対面、オンライン）
- 使える教材

## 手順
1. 学習の目標を「〜できる」の形で2〜3個に絞る。
2. 全体を「導入 → 説明 → 演習 → まとめ」で組み、時間を割り振る。
3. 説明は15分以内で区切り、演習を挟む。
4. 演習は、実際の業務に近い題材にする。
5. 確認テスト（小テストやチェックリスト）を作る。
6. 受講後のフォロー（質問窓口、復習資料）を決める。

## 出力形式
```
【目標】
【時間配分】
【内容】
【演習】
【確認テスト】
【フォロー】
```

## 例
入力：「新人に、請求書の処理方法を60分で教えたい。会計ソフトの基本操作は未経験」
出力のポイント：
- 目標：請求書を一人で登録できる。
- 構成：導入10分、説明15分、演習25分、確認10分。

## 注意
- 入力に無い社内ルールを作らない。
- 個人情報や機密を、演習の題材に使わない。
