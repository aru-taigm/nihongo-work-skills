# 学習計画（資格・試験）を作る

試験日から逆算し、全体の分量を日数で割る。計画は余裕を持たせ、遅れても取り戻せる予備日を入れる。

## 先に確認すること
- 試験の名称と日付
- 現在のレベルと、目標
- 使う教材と、その分量
- 1日・1週間に使える時間

## 手順
1. 試験日から逆算して、使える週数を出す。
2. 教材の分量（ページ、問題数）を週ごとに割り振る。
3. インプット → 問題演習 → 復習 → 模擬試験の順に期間を分ける。
4. 週に1日、予備日（遅れの調整）を入れる。
5. 1日の学習内容を、時間とともに具体的に書く。
6. 進み具合の確認方法（週末のテスト）を決める。
7. 直前期は、新しいことをせず復習に絞る。

## 出力形式
```
【全体の流れ】
【週ごとの計画】
【1日の例】
【確認のタイミング】
```

## 例
入力：「宅建を、あと3か月で。テキスト1冊（400ページ）と問題集。平日は1時間、休日は3時間」
出力のポイント：
- 3か月＝約12週。1〜6週：テキスト（1週約70ページ）、7〜10週：問題演習、11〜12週：模擬試験と復習。
- 週1日は予備日。

## 注意
- 入力に無い試験の出題範囲・日程を作らない。試験の最新情報は主催者の案内を確認するよう添える。
- 無理な計画を勧めず、続けられる量にする。
