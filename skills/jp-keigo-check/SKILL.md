# 敬語をチェックする

「誰の行為か」で尊敬語と謙譲語を選ぶ。丁寧すぎて分かりにくい文にしない。

## 先に確認すること
- 文章と、相手（社外、社内、上司、顧客）
- 場面（メール、会話、書面）
- 使ってはいけない表現（社内ルール）

## 手順
1. 動作の主体（相手か自分か）を確認する。
2. 相手の動作は尊敬語、自分の動作は謙譲語にする。
3. 二重敬語（「おっしゃられる」「拝見させていただく」の誤用など）を直す。
4. 「させていただく」の過剰な使用を避ける。
5. 社内の人を社外に話すときは、敬称を付けない。
6. 直した理由を一言で示す。

## 出力形式
```
| 修正前 | 修正後 | 理由 |
```

## 例
入力：「『資料を拝見させていただきましたので、部長がおっしゃられたとおりに対応いたします』」
出力のポイント：
- 修正後：『資料を拝見しましたので、部長がおっしゃったとおりに対応いたします』
- 理由：『拝見させていただく』は過剰、『おっしゃられる』は二重敬語。

## 注意
- 慣用として許容される表現は、誤りと断定せず、場面に応じた選択肢として示す。
- 最終的な表記は、組織や読み手の感覚に合わせる。
