# 口コミ・レビューへの返信を書く

返信は投稿者だけでなく、後から読む多くの人も見ている。感謝と誠実さを示し、言い訳や反論をしない。

## 先に確認すること
- 口コミの本文と評価（星の数）
- お店・会社として事実確認できていること（ミスがあったか）
- 返信の署名（店名、担当者名）と、トーン
- 連絡を求めてよい窓口（個別対応に移したい場合）

## 手順（好意的な口コミ）
1. 感謝を述べ、口コミに書かれた具体的な点を一つ拾う。
2. 次回への期待を短く添える。定型文の使い回しに見えないようにする。

## 手順（厳しい口コミ）
1. 不快な思いをさせたことへのお詫びを最初に述べる。
2. 指摘された事実を受け止める（事実確認ができていなければ「確認します」とする）。
3. 改善する点、または対応の方針を述べる。言い訳や投稿者への反論をしない。
4. 個別の対応が必要な場合は、公開の場に個人情報を書かず、窓口を案内する。
5. 事実と異なる内容でも、感情的に反論せず、「確認したところ〜」と淡々と事実を述べるにとどめる。

## 出力形式
```
（返信本文）3〜6文
署名：{店名}／{担当者}
```

## 例
入力：「★2。料理が出てくるまで40分かかった。店員の説明もなかった」（店は混雑が原因。待ち時間の案内が不十分だった）
出力のポイント：
- 「お待たせしてしまい、また事前のご案内が足りず、申し訳ございませんでした」
- 「混雑時の目安時間をお伝えするよう、スタッフ全員で共有いたしました」
- 反論や弁解は書かない。

## 注意
- 入力に無い改善策、割引、返金を勝手に約束しない。
- 公開の場に、投稿者の個人情報や来店履歴の詳細を書かない。
