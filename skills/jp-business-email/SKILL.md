# 敬語のビジネスメールを書く

丁寧すぎて回りくどいメールも、くだけすぎたメールも避ける。相手との関係に合わせた距離感で、用件が一読で伝わる文面にする。

## 先に確認すること
- 相手（社外の取引先、社内の上司、同僚、初めての相手）
- 用件（依頼、報告、確認、お断り、催促など）
- 期限や、相手にしてほしい行動

## 手順
1. 件名は【用件】＋具体的な内容（例：【ご確認のお願い】5月分見積書について）。
2. 本文は「宛名 → 挨拶・名乗り → 用件の要点 → 詳細 → 相手にしてほしいこと（期限つき）→ 結び → 署名」の順にする。
3. 尊敬語（相手の動作）と謙譲語（自分の動作）を取り違えない。二重敬語（「おっしゃられる」など）を避ける。
4. クッション言葉は1か所に絞る（「恐れ入りますが」「お手数ですが」を連続させない）。
5. 依頼は1通に1つを基本にする。複数あるときは番号を付ける。

## よく間違える表現
| 避ける | 使う |
|---|---|
| ご苦労様です（目上へ） | お疲れ様です／ありがとうございます |
| 了解しました（目上へ） | 承知しました |
| 参考になりました（目上へ） | 勉強になりました |
| おっしゃられる | おっしゃる |
| 拝見させていただきました | 拝見しました |
| 御社（話し言葉・メール）／貴社（書き言葉） | メールでは「貴社」が一般的 |

## 出力形式
```
件名：

{会社名}
{部署}{氏名}様

いつもお世話になっております。{自社名}の{氏名}です。

（要点）

（詳細）

お手数ですが、{期限}までにご返信いただけますと幸いです。
何卒よろしくお願い申し上げます。

--
署名
```

## 例
入力：「取引先の佐藤さんに、見積書の修正版を金曜までに確認してほしい」
出力：
```
件名：【ご確認のお願い】見積書（修正版）について

株式会社〇〇 佐藤様

いつもお世話になっております。△△の鈴木です。

先日ご指摘いただいた点を反映し、見積書の修正版を添付いたしました。
お手数ですが、金曜日（〇月〇日）までにご確認いただけますでしょうか。
ご不明な点がございましたら、お知らせください。

何卒よろしくお願い申し上げます。
```

## 注意
- 入力に無い日付、金額、固有名詞を作らない。足りなければ聞く。
- 文面を作ったら、宛名の敬称（様・御中）と添付の記載漏れを最後に点検する。
