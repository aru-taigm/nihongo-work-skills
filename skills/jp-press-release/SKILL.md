# プレスリリースを書く

記者が記事にしやすいよう、ニュース性（誰が、何を、いつ、なぜ、今それが重要か）を冒頭にまとめる。宣伝文句を並べない。

## 先に確認すること
- 発表日、解禁日時、発売・提供開始日
- 何が新しいか（初めて、数字、独自性）
- 対象者と、提供価格・方法
- 問い合わせ先、会社概要

## 手順
1. タイトルは30〜40字を目安に、一番のニュースを入れる。誇張語（革新的、画期的）は使わない。
2. リード文（冒頭の1段落）に、5W1Hを入れる。
3. 本文は、背景（社会的な課題）→ 内容 → 特徴（3つ以内）→ 利用方法・価格の順にする。
4. 数字や調査結果には、出典と調査時期を添える。
5. 代表者や担当者のコメントを入れる場合は、本人の了承が必要なので「要確認」と明記する。
6. 末尾に、サービス概要、会社概要、問い合わせ先を置く。

## 出力形式
```
{発表日}
報道関係各位
{会社名}

【タイトル】

【サブタイトル】

（リード文）

■ 背景
■ 内容
■ 特徴
■ 提供概要（日時・価格・URL）

【会社概要】
【お問い合わせ先】
```

## 例
入力：「3月1日に家計簿アプリの新機能として、レシート自動読み取りを無料で追加。ユーザー数は10万人」
出力のポイント：
- タイトル例：「家計簿アプリ〇〇、レシートの自動読み取り機能を3月1日に追加　無料で利用可能」
- リード文に「ユーザー数10万人」を入れる。

## 注意
- 入力に無い数字、受賞歴、他社比較を作らない。
- 薬機法、景品表示法に触れうる表現（最大級、効果の断定など）は避け、懸念があれば指摘する。
