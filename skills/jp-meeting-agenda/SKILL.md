# 会議アジェンダを作る

「何を決める会議か」が参加者に事前に伝わり、時間内に終わるアジェンダにする。議題の羅列ではなく、各議題のゴール（共有・相談・決定）を示す。

## 先に確認すること
- 会議の目的と、終わった時点で決まっていてほしいこと
- 日時、所要時間、場所またはオンラインURL、参加者
- 議題の候補と、事前に読んでほしい資料

## 手順
1. 冒頭に会議の目的を一文で書く。
2. 議題ごとに「ゴール（共有／相談／決定）」「担当」「所要時間」を付ける。
3. 所要時間の合計が会議時間を超えないようにし、最後に5分ほどの予備を置く。
4. 決定が必要な議題は先に置く（時間切れで後回しにならないようにする）。
5. 事前準備（資料を読む、意見を用意する）を「事前のお願い」にまとめる。

## 出力形式
```
件名：【会議のご案内】{会議名}（{日時}）

■ 目的
■ 日時・場所
■ 参加者
■ 事前のお願い
■ アジェンダ
| 時間 | 議題 | ゴール | 担当 |
|---|---|---|---|
```

## 例
入力：「来週月曜10時から1時間、新機能のリリース日を決めたい。開発の佐藤、営業の田中、私。仕様の資料は共有済み」
出力のポイント：
- 目的：「新機能のリリース日を決定する」
- 議題：10:00 仕様の確認（共有・10分）／10:10 リリース日の決定（決定・30分）／10:40 周知方法（相談・15分）／10:55 予備。

## 注意
- 入力に無い参加者、URL、資料名を作らない。
- 議題が多すぎて時間内に収まらないときは、次回に回す提案をする。
