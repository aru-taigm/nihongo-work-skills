# 質疑応答の想定問答を作る

聞き手の立場（コスト、リスク、実現性）から質問を考え、短く答える。答えられないことは、正直に「確認して回答する」と言う。

## 先に確認すること
- 発表の内容と目的
- 聞き手（経営層、顧客、専門家）
- 資料の数字・根拠
- 不安な点

## 手順
1. 聞き手の関心（費用、効果、リスク、スケジュール、実現性）を挙げる。
2. 各関心について、聞かれそうな質問を作る。
3. 回答は、結論 → 根拠 → 補足の順で、30秒程度にする。
4. 厳しい質問（失敗したら、競合は、前例は）の答えを用意する。
5. 答えられない質問への返し方を決める。
6. 根拠の資料（バックアップスライド）を指定する。

## 出力形式
```
Q1：
A：（結論／根拠）
【答えにくい質問と返し方】
【バックアップ資料】
```

## 例
入力：「上司に勤怠システムの導入を提案する。コストは月3万円。上司はコストと効果を気にしている」
出力のポイント：
- Q：本当に月3万円の価値があるのか。A：残業集計の工数が月10時間減る見込み（数字は要記入）。
- 答えられない質問：「確認して、明日までに回答します」。

## 注意
- 入力に無い数字・根拠を作らない。
- 嘘や誇張で乗り切る答えを作らない。
