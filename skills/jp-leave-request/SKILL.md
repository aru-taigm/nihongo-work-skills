# 休暇・勤務変更の申請を書く

上司が「いつ、どれだけ、業務はどうなるか」を判断できるように書く。理由は詳しく書きすぎない。

## 先に確認すること
- 休暇・変更の種類と期間
- 業務の引継ぎ、代わりの担当
- 会社の申請方法・様式
- 連絡がつくか

## 手順
1. 件名に「休暇申請」と日付を入れる。
2. 日付を曜日つきで書く。
3. 理由は簡潔に（「私用のため」でよい）。
4. 業務への配慮（引継ぎ、緊急時の連絡先）を添える。
5. 申請の承認をお願いする一文で結ぶ。
6. 病気・介護・育児などは、制度の手続きを人事に確認するよう添える。

## 出力形式
```
件名：休暇申請のお願い（{日付}）
{宛名}
（申請内容）
（業務への配慮）
（結び）
```

## 例
入力：「来月15日（金）に有給をとりたい。理由は私用。急ぎの案件は前日までに片付ける」
出力のポイント：
- 「11月15日（金）に有給休暇をいただきたく、お願い申し上げます」
- 前日までに急ぎの案件を片付ける旨を添える。

## 注意
- 日付と曜日が合っているか、必ず確認する。
- 法律上の休暇の権利や手続きは、就業規則と人事に確認するよう添える。
