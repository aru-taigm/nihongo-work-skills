# 挨拶・スピーチの原稿を作る

耳で聞いて分かる、短い文で組み立てる。長さは字数で管理し、1分は約300字を目安にする。

## 先に確認すること
- 場面、聞き手、時間
- 話す人の立場と、故人や主役との関係
- 入れたいエピソード・エピソードの事実
- 避けたい話題、忌み言葉

## 手順
1. 構成は「挨拶 → 本題（エピソード1つ）→ 結び」にする。
2. エピソードは一つに絞り、場面が目に浮かぶ描写にする。
3. 一文を短くし、「、」で区切って息継ぎできるようにする。
4. 場に応じた型を使う（乾杯は「ご唱和」、結婚式は忌み言葉を避ける）。
5. 時間に収まる字数に調整する。
6. 最後に、話す前の確認事項（呼び方、固有名詞の読み）を添える。

## 出力形式
```
【原稿】（約{n}字／{n}分）
【話すときのポイント】
```

## 例
入力：「同僚の送別会で乾杯の挨拶。1分。エピソード：彼が徹夜でトラブルを解決してくれたことがある」
出力のポイント：
- 冒頭の挨拶、徹夜で対応してくれた場面、感謝、乾杯の発声の順で約300字にまとめる。

## 注意
- 入力に無いエピソードを作らない。
- 結婚式や葬儀は地域・宗派で作法が異なるため、主催者に確認するよう添える。
