# 休暇・遅刻・欠勤の連絡を書く

急ぎの連絡は、結論（休む・遅れる）と、業務への影響・対応を最初に伝える。理由は詳しく書く必要はない。

## 先に確認すること
- 種類（有給休暇、遅刻、欠勤、早退、不在の自動返信）
- 日時（休む日、到着予定時刻）
- 緊急の連絡先と、業務の引き継ぎが必要か
- 連絡手段（電話が必要か、チャット・メールでよいか。職場のルールに従う）

## 手順（急な欠勤・遅刻）
1. 件名または1行目に「本日は〇〇のため、△△」と結論を書く。
2. 到着予定または復帰予定を書く。未定なら「分かり次第連絡する」。
3. 影響のある業務（会議、締め切り）と、代わりの対応を書く。
4. お詫びを一言添える。

## 手順（休暇の申請）
1. 日付と期間、取得する休暇の種類を書く。
2. 業務の引き継ぎ（担当、連絡先）を書く。
3. 申請は余裕をもって。繁忙期は事前に上司へ口頭で相談するよう添える。

## 手順（不在の自動返信）
1. 不在期間、戻る日、緊急時の連絡先（代理者名）を書く。

## 出力形式
```
件名：
{宛名}
{結論}
{影響と対応}
{お詫び・結び}
```

## 例
入力：「今朝から熱がある。今日は休みたい。午前の会議は田中さんに頼んだ」
出力：
```
件名：【本日休暇のご連絡】
〇〇部長
おはようございます。〇〇です。
体調不良のため、本日はお休みをいただきたく存じます。
午前10時の定例会議は、田中さんに代理をお願いしました。
急な連絡となり、申し訳ありません。
```

## 注意
- 入力に無い診断や理由を作らない。私的な事情は、書く範囲を本人に確認する。
- 法定の休暇の扱いは会社の規定と労働基準法に従う。
