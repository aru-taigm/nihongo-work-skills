# 求人票を書く

応募者が「自分に合うか」を判断できる情報（仕事内容、条件、働き方）を、誇張せず具体的に書く。

## 先に確認すること
- 職種、雇用形態、勤務地、勤務時間、給与（範囲）
- 仕事内容、チームの規模、使うツールや技術
- 必須の経験、歓迎する経験
- 選考プロセスと、入社時期

給与や休日などの条件は、入力にあるものだけを書く。無い項目は「要記入」と残す。

## 手順
1. タイトルは「職種＋特徴」を書く（例：Webエンジニア｜自社プロダクト開発・フルリモート可）。
2. 冒頭に、この仕事の意義と、入社後に任せたい仕事を3行で書く。
3. 仕事内容は、1日の流れや担当範囲が想像できる書き方にする。
4. 必須要件は最小限にし、歓迎要件と分ける。
5. 年齢や性別などで応募を制限する表現を使わない（雇用対策法・男女雇用機会均等法の観点）。
6. 給与は、固定残業代を含む場合は金額と時間数を明記する。
7. 選考の流れと、応募方法を末尾に置く。

## 出力形式
```
【タイトル】
■ このポジションについて
■ 仕事内容
■ 応募資格（必須／歓迎）
■ 給与・待遇
■ 勤務地・勤務時間・休日
■ 選考プロセス
■ 会社について
```

## 例
入力：「事務のアルバイト。週3日、10〜16時、時給1,200円、渋谷。Excelが使える人」
出力のポイント：
- 必須：Excelの基本操作（関数の使用経験など、具体的に）。
- 休日、交通費、選考の流れは入力に無いため「要記入」として示す。

## 注意
- 入力に無い福利厚生、年収、平均残業時間を作らない。
- 「アットホーム」「やりがい」のような中身のない言葉に頼らない。
