# 請求書を作る・点検する（インボイス制度対応）

適格請求書に必要な項目が揃っているかを確認しながら、請求書の内容を組み立てる。

## 先に確認すること
- 発行する側が適格請求書発行事業者か（登録番号 T＋13桁があるか）
- 取引先名、取引日（または請求の対象期間）、品目と金額
- 軽減税率（8%）の対象品目があるか
- 支払期限と振込先

登録番号が無い場合は、適格請求書にならないことを伝え、通常の請求書として作る。

## 適格請求書の必須項目（国税庁の定め）
1. 発行事業者の氏名または名称、登録番号
2. 取引年月日
3. 取引内容（軽減税率の対象品目は、その旨が分かるように）
4. 税率ごとに区分して合計した対価の額（税抜または税込）と適用税率
5. 税率ごとに区分した消費税額等
6. 書類の交付を受ける事業者の氏名または名称

## 手順
1. 入力の金額を税率ごとに分けて集計する。消費税額は税率ごとに1回だけ端数処理する（明細ごとに処理しない）。
2. 端数処理（切り捨て・切り上げ・四捨五入）は、先方との取り決めか発行側の方針に従う。決まっていなければ聞く。
3. 上の必須項目が全部入っているかを表で点検し、足りない項目を示す。
4. 支払期限と振込先を末尾に入れる。

## 出力形式
```
請求書
請求書番号：
発行日：
{取引先名} 御中

{発行者名}
登録番号：T0000000000000
住所／連絡先：

件名：
下記のとおりご請求申し上げます。

| 品目 | 数量 | 単価 | 税率 | 金額（税抜） |
|---|---|---|---|---|

10%対象 小計（税抜）：   消費税：
8%対象（※軽減税率） 小計（税抜）：   消費税：
合計（税込）：

お支払期限：
お振込先：
```

## 例
入力：「デザイン制作 150,000円、納品用の菓子折り 3,240円（8%、税込）。登録番号 T1234567890123」
出力のポイント：
- 10%対象：150,000円（税抜）、消費税15,000円。
- 8%対象（※）：3,000円（税抜）、消費税240円。
- 合計：168,240円（税込）。

## 注意
- 税率や制度は改正されることがある。実際に発行する前に、国税庁の最新の案内で確認するよう添える。
- 税務・法律の判断が必要な場合は、税理士への相談を勧める。
