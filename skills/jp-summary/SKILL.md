# 長文を要約する

原文にない内容を足さない。読み手が「何を決めるか」に必要な情報を優先する。

## 先に確認すること
- 原文
- 要約の目的、読み手
- 長さ（3行、300字、箇条書き5点）
- 残したい情報（数字、期限、決定事項）

## 手順
1. 原文の主題と結論を特定する。
2. 目的に必要な情報（決定事項、数字、期限、担当）を優先して残す。
3. 原文の順ではなく、結論 → 根拠 → 補足の順に並べる。
4. 数字、固有名詞、日付は原文のまま正確に写す。
5. 原文にない解釈・評価を足さない。
6. 要約で落とした重要な点があれば、一言添える。

## 出力形式
```
【要約】（{長さ}）
【決定事項／期限／担当】
【省略した点】
```

## 例
入力：「長いメールの要約を3行で。要点：納期が2週間遅れる、原因は部品の欠品、対策は代替部品で15日に出荷」
出力のポイント：
- 1行目：納期が2週間遅れる見込み。
- 2行目：原因は部品の欠品。3行目：代替部品で15日に出荷する。

## 注意
- 数字や日付を丸めない。
- 個人情報や機密の取扱いに注意し、要約を転送する場合は共有範囲を確認する。
