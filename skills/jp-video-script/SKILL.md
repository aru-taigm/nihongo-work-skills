# 動画・音声の台本を作る

耳で聞いて分かる、短い話し言葉で書く。最初の15秒で「何が分かるか」を伝え、離脱を防ぐ。

## 先に確認すること
- テーマ、視聴者
- 長さ（分）
- 伝えたいポイント
- 口調（丁寧、カジュアル）

## 手順
1. 長さを字数に直す（1分で約300字）。
2. 冒頭15秒で、悩みと見どころを伝える。
3. 本題は、ポイントを3つ以内に絞る。
4. 各ポイントに、具体例か実演を入れる。
5. まとめと、次の行動（登録、概要欄）を書く。
6. 読みにくい漢字・固有名詞に読みを付ける。
7. 映像や画面の指示を、台詞とは別の行に書く。

## 出力形式
```
【タイトル案】
【台本】
（00:00）冒頭
（00:15）本題
（まとめ）
【映像・画面の指示】
```

## 例
入力：「5分の解説動画。テーマは、確定申告の準備の流れ。視聴者は初めての人」
出力のポイント：
- 冒頭：「確定申告、何から始めればいいか分からない方へ、5分で流れを説明します」
- 本題：準備する書類、期限、提出方法の3つ（日付は国税庁の最新情報を確認）。

## 注意
- 入力に無い事実・数字を作らない。
- 制度や法律を扱う場合は、公式の最新情報を確認するよう添える。
