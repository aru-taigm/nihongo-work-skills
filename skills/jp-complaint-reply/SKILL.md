# クレームへの返信を書く

まず相手の不快な気持ちを受け止め、事実と責任範囲を切り分けて、具体的な対応を示す。言い訳や責任転嫁をしない。

## 先に確認すること
- クレームの内容（日時、商品、状況）
- 事実として確認できていること
- 会社として取れる対応（返金、交換、再発防止）
- 返信の窓口と期限

## 手順
1. 冒頭で、不快な思いをさせたことへのお詫びを書く。
2. クレームの内容を要約して、受け止めたことを示す。
3. 確認できた事実と、調査中の点を分けて書く。
4. 原因が分かっていれば簡潔に、分からなければ調査の期限を示す。
5. 具体的な対応と、再発防止策を書く。
6. 連絡窓口を明記して結ぶ。

## 出力形式
```
件名：{件名}につきまして（お詫びとご報告）
{宛名}様
（お詫び）
（ご指摘の要約）
（事実確認の結果）
（対応と再発防止）
（連絡先）
```

## 例
入力：「通販で注文品が破損して届いたと連絡があった。交換品を送る手配ができる。再発防止は梱包の見直し」
出力のポイント：
- 「このたびは、商品が破損した状態でお届けし、ご不快な思いをさせてしまいましたこと、深くお詫び申し上げます」
- 対応：交換品を○日までに発送。再発防止：梱包の見直し。

## 注意
- 入力に無い原因や補償を約束しない。
- 法的責任や損害賠償に関わる場合は、専門家や上司の確認を経るよう添える。
