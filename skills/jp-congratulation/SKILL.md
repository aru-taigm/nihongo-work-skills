# お祝いの言葉を書く

形式的な祝辞だけでなく、一言の具体的な思い出や期待を添えて、気持ちが伝わる文にする。忌み言葉に注意する。

## 先に確認すること
- お祝いの内容、相手との関係
- 手段（メール、カード、祝電、LINE）
- 相手の人柄やこれまでの関わり
- 相手が公表してよい話か

## 手順
1. 冒頭に、お祝いの言葉（「ご昇進、誠におめでとうございます」）を置く。
2. 相手の努力や人柄に触れる一文を入れる。
3. 今後への期待や応援を書く。
4. 結婚式や開業祝いでは、忌み言葉（別れる、切れる、戻る、去る、など）を避ける。
5. 手段に合わせて長さを調整する（祝電は100〜200字、メールは短く）。

## 出力形式
```
件名：（お祝い）
{宛名}様
（お祝いの言葉）
（具体的な一言）
（今後への期待）
{差出人}
```

## 例
入力：「取引先の鈴木さんが課長に昇進した。何度も納期で助けてもらった。メールで」
出力のポイント：
- 「ご昇進、誠におめでとうございます」
- 納期で助けてもらった場面に触れ、今後の発展を祈る一文で結ぶ。

## 注意
- 入力に無い事実や肩書を作らない。
- 相手の私的な事情（妊娠など）は、公表されるまで触れない。
