# 確定申告の準備を手伝う（個人事業主向け）

帳簿の下ごしらえをする。申告書の提出や税額の最終判断は、国税庁の案内と税理士に確認する前提で進める。

## 先に確認すること
- 青色申告か白色申告か（青色申告承認申請書を出しているか）
- 消費税の課税事業者か、免税事業者か
- 対象の年と、材料（通帳、クレジットカード明細、領収書、請求書）
- 自宅兼事務所か（家事按分が必要になる）

## 手順
1. 明細を1行ずつ、売上／経費／事業に無関係（私用）に分ける。迷うものは「要確認」にする。
2. 経費は勘定科目に仕分ける。よく使う科目：通信費、水道光熱費、地代家賃、消耗品費、旅費交通費、接待交際費、会議費、広告宣伝費、支払手数料、外注費、減価償却費、租税公課。
3. 家賃、通信費、電気代など、私用と共用のものは「家事按分」の割合を聞く。割合の根拠（面積、利用時間）も記録するよう勧める。
4. 10万円以上の高額な購入は、減価償却の対象になることがあるため「要確認」に入れる。
5. 領収書や請求書が無いものを一覧にする。
6. 仕訳の結果を表にまとめ、科目別の合計を出す。

## 出力形式
```
| 日付 | 摘要 | 金額 | 区分 | 勘定科目 | メモ |
|---|---|---|---|---|---|

科目別合計：
要確認一覧：
証憑が不足しているもの：
```

## 例
入力：「5/3 ワコム液タブ 48,000円 / 5/10 友人との飲食 6,000円 / 5/20 自宅インターネット 5,000円（仕事7割）」
出力のポイント：
- 液タブ：消耗品費（10万円未満）。
- 飲食：目的が事業か私用かで接待交際費または私用。「誰と何の目的か」を聞く。
- インターネット：通信費 3,500円（5,000円×7割）、残りは私用。

## 注意
- 申告期限、控除額、要件は毎年変わりうる。最新の国税庁の案内を確認するよう添える。
- 「経費になるか」は事実関係で決まる。断定せず、判断材料と確認先（税務署、税理士）を示す。
- 売上や領収書の中身を作らない。
