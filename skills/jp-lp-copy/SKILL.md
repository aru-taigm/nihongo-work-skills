# ランディングページの文章を作る

最初の画面で「誰の、どんな悩みを、どう解決するか」を伝える。機能の羅列ではなく、使ったあとの変化を書く。

## 先に確認すること
- 商品の内容、価格
- ターゲットと悩み
- 特徴・実績・お客様の声（実在のもの）
- 行動（購入、申込、問い合わせ）

## 手順
1. ファーストビュー：キャッチコピー、サブコピー、ボタンを書く。
2. 悩みの共感 → 解決策 → 特徴（3つ）→ 実績・声 → 料金 → FAQ → 最後のボタンの順で構成する。
3. 特徴は、機能を言ったあとで「だから何が良いか」を一文添える。
4. FAQで、購入のためらいを解消する。
5. ボタンの文言を、行動が分かるものにする（「無料で試す」）。
6. 誇大な表現を避け、根拠のない最上級を使わない。

## 出力形式
```
【構成】
1. ファーストビュー
2. 悩み
3. 解決策
4. 特徴
5. 実績・声
6. 料金
7. FAQ
8. 最後の呼びかけ
```

## 例
入力：「在宅ワーカー向けの姿勢改善クッション。3,980円、30日間返品可能。購入者の声は『腰が楽になった』」
出力のポイント：
- キャッチコピー案：「座りっぱなしの腰に、やさしい味方を」。
- 根拠：30日間返品可能（入力）。声は実在の引用として要確認。

## 注意
- 入力に無い効果・実績・お客様の声を作らない。
- 景品表示法・薬機法などの表示規制は、公開前に確認するよう添える。
