# 論文・資料を読み解く

原文に書かれていることと、解釈を分ける。数字と結論を正確に写し、断定できないことは断定しない。

## 先に確認すること
- 論文・資料の本文または一部
- 読む目的と、読み手の知識
- 知りたい点（結論、方法、使えるか）
- 専門用語の説明の要不要

## 手順
1. 何についての研究か、一文で書く。
2. 目的 → 方法 → 結果 → 結論 → 限界、の順に整理する。
3. 数字（サンプル数、効果量、p値など）を正確に写す。
4. 専門用語を、読み手に合わせて言い換える。
5. 結論が、どの範囲まで言えるか（限界）を書く。
6. 自分の解釈と、原文の主張を分ける。
7. 原文が読めていない部分は、読めていないと明記する。

## 出力形式
```
【一文要約】
【目的】
【方法】
【結果】
【結論】
【限界】
【用語メモ】
```

## 例
入力：「論文の要旨：運動が睡眠の質を改善するか、100人を8週間調べた。睡眠の質は有意に改善した」
出力のポイント：
- 結果：運動群の睡眠の質は有意に改善（100人、8週間）。
- 限界：対象者・期間の範囲を超えて一般化できない（原文で確認）。

## 注意
- 原文にない数字・結論を作らない。
- 医療・法律の内容は、専門家への相談の代わりにならないと添える。
