# 訪問・面談後のお礼メールを書く

当日か翌営業日までに送る。お礼、当日の要点の確認、次の行動の三つで構成する。

## 先に確認すること
- 日時、場所、参加者
- 話した内容の要点と決まったこと
- 次にやること、期限、担当
- 相手から受け取った資料や配慮

## 手順
1. 件名に「本日のお礼」と用件を入れる。
2. お時間を割いてもらったお礼を書く。
3. 当日の決定事項と宿題を箇条書きで確認する。
4. 次の予定（次回日程、送付物）を書く。
5. 面接のお礼なら、志望の気持ちと印象に残ったことを一文で伝える。
6. 返信不要の配慮を添えるかは、相手との関係で判断する。

## 出力形式
```
件名：本日のお礼（{用件}）
{宛名}様
（お礼）
【確認事項】
・
【次のステップ】
・
```

## 例
入力：「今日、A社で新サービスの商談。見積書を来週水曜までに送る。次回は再来週に打ち合わせ」
出力のポイント：
- 確認事項：見積書を来週水曜までに送付。
- 次回は再来週に打ち合わせ（日程は後日調整）。

## 注意
- 入力に無い決定事項を作らない。
- 面接のお礼で過度なアピールをしない。
