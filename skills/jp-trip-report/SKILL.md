# 出張・訪問報告を書く

読み手が「行った価値があったか、何をするか」を判断できるように、成果と次のアクションを先に書く。

## 先に確認すること
- 目的と期間、行き先
- 会った人、見たもの、聞いた話
- 得られた情報・成果
- 費用、次にやること

## 手順
1. 最初に要約（目的と結論）を3行で書く。
2. 行程を日付順に書く。
3. 成果・学びを、事実と所感に分けて書く。
4. 自社への活用案と、次のアクション（担当・期限）を書く。
5. 費用の内訳を書く（領収書と照合するよう添える）。
6. 写真・資料の添付を指示する。

## 出力形式
```
出張報告書
【要約】
【目的・期間・行き先】
【行程】
【成果・学び】
【今後のアクション】
【費用】
```

## 例
入力：「大阪で展示会。10月3日〜4日。競合の新製品を見た。ブースで3社と名刺交換」
出力のポイント：
- 要約：競合の新製品の機能を確認。3社と名刺交換し、うち1社に提案の機会がある（要確認）。
- 次のアクション：名刺交換した3社へのお礼メール（担当・期限は要記入）。

## 注意
- 入力に無い成果・費用を作らない。
- 取引先との会話の内容は、機密に配慮して書く。
