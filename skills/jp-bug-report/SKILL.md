# バグ報告・問い合わせを書く

読み手が1回で再現できることが最優先。感情や推測は分けて書き、事実を先に書く。

## 先に確認すること
- 何が起きたか
- どうすれば起きるか
- 環境（OS、バージョン、ブラウザ）
- エラーメッセージ・画面のスクリーンショット

## 手順
1. タイトルを、「どこで・何が起きる」で書く。
2. 再現手順を、番号つきで1操作ずつ書く。
3. 期待する動作と、実際の動作を分けて書く。
4. 環境（OS、アプリのバージョン、ブラウザ）を書く。
5. エラーメッセージを、そのまま引用する。
6. 再現率（毎回、時々）と、回避策があれば書く。
7. 機密情報（パスワード、個人情報）を伏せる。

## 出力形式
```
タイトル：
【再現手順】
【期待する動作】
【実際の動作】
【環境】
【補足（ログ・画像）】
```

## 例
入力：「Windows 11でアプリを開いて保存ボタンを押すとフリーズする。Ver 1.2.0。毎回起きる」
出力のポイント：
- タイトル：保存ボタンを押すとアプリがフリーズする（Windows 11、v1.2.0）。
- 再現率：毎回。

## 注意
- 入力に無い再現手順やログを作らない。
- 報告先の様式（テンプレート）があれば、それに従う。
