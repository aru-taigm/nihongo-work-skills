# 自己評価・振り返りを書く

評価者が「何を、どれだけやったか」を短時間で把握できるように、事実と成果を中心に書く。自己評価が低すぎても高すぎても伝わらない。

## 先に確認すること
- 評価期間、目標（あれば）
- 実施した業務・プロジェクト
- 成果の数字（売上、時間削減、件数）
- 上司から言われたフィードバック

## 手順
1. 期間の目標ごとに、達成度を数値で書く。
2. 成果は、状況 → 自分の行動 → 結果、の順に書く。
3. 周囲への貢献（後輩の指導、チームへの共有）も書く。
4. できなかったことは、原因と次の対策を添えて正直に書く。
5. 来期の目標と、そのために伸ばしたい力を書く。
6. 「頑張りました」などの抽象的な表現を、事実に置き換える。

## 出力形式
```
【期間の目標と達成度】
【主な成果（状況・行動・結果）】
【周囲への貢献】
【課題と対策】
【来期の目標】
```

## 例
入力：「営業。今期の目標は売上1000万円で、実績は1100万円。新人の指導もした。ただ新規開拓が計画の半分だった」
出力のポイント：
- 達成：売上1,100万円（目標比110%）。
- 課題：新規開拓が計画の50%。原因（時間配分）と対策（週の枠を決める）を添える。

## 注意
- 入力に無い成果を作らない。数字は根拠と一緒に書く。
- 他人の成果を自分のものとして書かない。
