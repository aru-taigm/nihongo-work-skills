# 事業計画書を作る

読み手（金融機関、審査員、上司）が「儲かるのか」「実現できるのか」を判断できるよう、根拠のある数字と、自分の強みを示す。

## 先に確認すること
- 提出先と目的（日本政策金融公庫の創業計画、補助金、社内の新規事業）。提出先の様式があればそれに合わせる
- 事業の内容、顧客、提供価値
- 資金（自己資金、必要な資金、使いみち）
- 経験（なぜ自分がやるのか）

## 手順
1. 事業の概要を、誰に、何を、どう売るかの一文にする。
2. 課題と顧客：顧客が困っていることを、事実や数字で示す。
3. 商品・サービスと価格：価格の根拠（原価、競合）を書く。
4. 市場と競合：競合の名前と、自分の差別化点を書く。市場規模は出典つきで。
5. 売上計画：客数×単価×回数など、分解した式で書く。根拠の無い大きな数字を書かない。
6. 費用と資金繰り：固定費、変動費、必要な資金と使いみち。
7. 体制とスケジュール：開業までと、開業後1年の目標。
8. リスクと対策。
9. 数字は、入力にあるものだけを使い、無い項目は「要記入」とする。

## 出力形式
```
事業計画書：{事業名}
1. 事業の概要
2. 課題と顧客
3. 商品・サービスと価格
4. 市場と競合
5. 売上計画（式つき）
6. 費用・資金計画
7. 体制・スケジュール
8. リスクと対策
9. 申請者の経歴・強み
```

## 例
入力：「古民家カフェを開業したい。客単価1,000円、1日平均30人、月25日営業。家賃は月8万円」
出力のポイント：
- 月の売上：1,000円×30人×25日＝75万円（想定。根拠は要記入）。
- 費用：家賃8万円のほか、原価、人件費、水道光熱費は「要記入」。

## 注意
- 入力に無い売上や市場規模を作らない。計画の数字は「想定」と明記する。
- 融資や補助金の要件・様式は変わるため、提出先の最新の案内で確認するよう添える。
