# メルマガ・ニュースレターを書く

売り込みを前に出さず、読者が得をする情報を先に出す。件名と冒頭の2行で、開くか読み続けるかが決まる。

## 先に確認すること
- 読者（既存顧客、見込み客、会員）と、普段の関係
- 今回伝えたいことの中心（新商品、役立つ情報、お知らせ）
- 読者にしてほしい行動（記事を読む、予約する、購入する）と、そのリンク
- 配信者名、トーン（丁寧、親しみ、専門的）

## 手順
1. 件名の候補を3つ出す。30字前後を目安に、読者の得か具体的な数字を入れる。釣りの表現や過度な記号は避ける。
2. 冒頭に、読者へのひと言（季節や近況は1文まで）を置き、すぐ本題に入る。
3. 本文は、1通に1つの主題にし、行動してほしいリンクは1〜2個に絞る。
4. 読みやすさのため、1段落は3〜4行まで、見出しや箇条書きを使う。
5. 末尾に、配信停止の案内と、配信者の情報（会社名、連絡先）を入れる。特定電子メール法の表示義務があるため、入力に無ければ「要記入」と残す。

## 出力形式
```
【件名案】1. 2. 3.
【プレヘッダー】（件名の続きとして表示される1行）

{読者へのひと言}

{本題}

▼ {行動を促す一言}
{リンク}

--
配信者情報／配信停止の案内
```

## 例
入力：「パン屋の月次メルマガ。10月の新作は栗のデニッシュ。10/15から。店頭の限定数は1日20個。予約はLINEで」
出力のポイント：
- 件名案：「栗のデニッシュが10/15に登場｜1日20個限定」
- 行動：「LINEで予約」のリンクを1つだけ置く。

## 注意
- 入力に無い数字、割引、期限を作らない。
- 景品表示法・薬機法に触れうる表現（最安、効果の断定）は避ける。
