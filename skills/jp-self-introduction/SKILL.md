# 自己紹介を作る

相手が覚えて、次の会話につなげられる自己紹介にする。「名前＋何をしている人か＋一つ印象に残る事実＋今日の目的」の順で組む。

## 先に確認すること
- 場面（面接、勉強会、新しい職場）と時間
- 相手（上司、同僚、初対面の参加者）
- 話したい経歴・強み・趣味
- 記憶に残したいこと

## 手順
1. 時間を字数に直す（30秒で約150字、1分で約300字、3分で約900字）。
2. 名前と所属を最初に、読み方を添える。
3. 現在の仕事を、専門用語を避けて一文で書く。
4. 印象に残る具体的な事実を一つ入れる（数字や、意外な経験）。
5. 今日の目的か、相手への一言（「○○について話したい」）で締める。
6. 話し言葉で、声に出して読んだときに詰まらない文にする。

## 出力形式
```
【30秒版】
【1分版】
【3分版】（必要な場合）
```

## 例
入力：「勉強会で1分。名前は田中、Web制作会社でデザイナー。猫を3匹飼っている。デザインの話がしたい」
出力のポイント：
- 「田中と申します。Web制作会社でデザインをしています。家には猫が3匹いて、制作中は膝の上で見守られています。今日はデザインの話ができればと思います」（約90字、30秒版）。

## 注意
- 入力に無い経歴や実績を作らない。
- 個人情報（住所、家族の詳細）は書かない。
