# スライドの構成を作る

スライドは「1枚1メッセージ」。結論から先に、聞き手が決めること（承認、購入、理解）に向かって並べる。

## 先に確認すること
- 目的（何を決めてもらいたいか）
- 聞き手と、持っている知識
- 持ち時間、枚数
- 手元の資料・数字

## 手順
1. 聞き手に取ってほしい行動を一文にする。
2. 全体を「結論 → 背景・課題 → 解決策 → 効果と根拠 → 進め方 → お願い」の流れにする。
3. 各スライドのタイトルを、結論を述べる文にする（「売上が下がっている」ではなく「売上は3か月連続で下がっている」）。
4. 各スライドの要点を、箇条書き3点以内で書く。
5. 使う図表の種類を指定する。
6. 時間配分（1枚1〜2分）に合わせて枚数を決める。

## 出力形式
```
【目的】
【スライド構成】
1. タイトル：（要点）／図表：
2. …
```

## 例
入力：「上司に、新しい勤怠システムの導入を提案する。10分。コストは月3万円、残業の集計が楽になる」
出力のポイント：
- 1. 結論：勤怠システムを導入したい（月3万円）。
- 2. 現状の課題：集計に月10時間（数字は要記入）。3. 解決策と効果。

## 注意
- 入力に無い数字を作らず、根拠が必要な箇所は「要記入」とする。
- 資料の体裁（色、フォント）は組織の規定に合わせるよう添える。
