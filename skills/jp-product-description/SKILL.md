# 商品説明文を書く

買う人が「自分に合うか」「失敗しないか」を判断できるようにする。良いところだけでなく、サイズ・状態・注意点も正直に書く。

## 先に確認すること
- 商品名、カテゴリ、価格帯、販売先（自社EC、モール、フリマ）
- 仕様（サイズ、素材、重量、色、付属品）
- 想定する購入者と、使う場面
- 状態（新品／中古）と、傷や汚れなどの注意点

## 手順
1. 冒頭のキャッチは、誰の何の悩みを解決するかを一文にする。
2. 特徴は3〜5個。「何が良いか」だけでなく「使うとどうなるか」まで書く。
3. 仕様は箇条書きにし、単位を明記する。
4. 注意点（サイズ感、色味の差、使用上の注意）を、購入前に分かる位置に書く。
5. 中古の場合は、傷や使用感の程度を具体的に書く。
6. 薬機法・景品表示法・食品表示に触れうる表現（効く、治る、No.1など）を避ける。根拠が示せない表現は使わない。

## 出力形式
```
【商品名】
【キャッチコピー】
【特徴】
-
【仕様】
-
【ご注意】
【配送・返品】（入力にあれば）
```

## 例
入力：「帆布のトートバッグ。A4が入る。縦30×横38×マチ10cm。生地は綿100%。色はベージュ。内ポケット1つ」
出力のポイント：
- キャッチ：「A4の書類がそのまま入る、毎日使える帆布のトート」
- 仕様：縦30×横38×マチ10cm、綿100%、ベージュ、内ポケット1つ。
- 注意：画面により色味が異なる場合があります（実際の色は入力に無いので、一般的な注意として添える）。

## 注意
- 入力に無い機能、素材、産地、受賞歴を作らない。
- 画像で伝わる情報と、文章で補う情報を分けて考える。
