# やさしい日本語に書き換える

情報を減らさず、短い文・易しい語・曖昧さの少ない表現に直す。漢字には読みを付けるかを、対象者に合わせて決める。

## 先に確認すること
- 元の文章
- 読み手（日本語のレベル、年齢）
- 媒体（掲示、メール、チラシ）
- ふりがなの要不要

## 手順
1. 一文を短くし、一文に一つの情報にする。
2. 難しい言葉を、易しい言葉に言い換える（「提出する」→「出す」）。
3. 二重否定、受け身の多用、あいまいな表現（「検討する」）を避ける。
4. 日付・時間・場所・持ち物を、箇条書きにする。
5. 災害情報などは、最初に「何をするか」を書く。
6. ふりがなが必要な場合は、（ ）で付ける。
7. 元の意味が変わっていないか確認する。

## 出力形式
```
【やさしい日本語】
【言い換えた語の一覧】
【確認事項】
```

## 例
入力：「『明日の説明会は、所定の用紙に記入のうえ、受付に提出してください。』」
出力のポイント：
- 出力：『あしたの説明会では、紙に名前や住所を書いて、受付に出してください。』
- 元の「所定の用紙」の内容は、確認が必要。

## 注意
- 元の情報を省略しない。意味が変わる言い換えをしない。
- 災害・法律・医療の情報は、公的機関の表現を確認するよう添える。
